# v1.2.7 언어·한국 등급분류 확인

확인일: 2026-09-14. 제품 기준 v1.2.7 / 076d706b66f4844137c18a4a77386397873dce66.

## 실제 언어 범위

한국어/English 선택과 전환 코드는 존재한다. scripts/core/LanguageSettings.gd가 읽는 data/localization/v122_stage10_ui.json에는 영어142키가 있으며 settings61, name20, tutorial61로 구성된다. 등록된 범위 이름도 settings/name_entry/tutorial_day1_3이다. 전투·관리·성장·결과·후반 스토리 전체 영어 현지화가 완료됐다는 근거는 없다. LanguageSettings와 카탈로그·GameRoot는 출시 태그와 동일한 파일임을 git diff로 확인했다. 이번에는 영어 실플레이 회귀를 수행하지 않았다.

따라서 기존의 '영어가 전혀 없다'는 설명은 부정확하다. 정확한 설명은 '영어 선택 및 일부 번역이 있으나 전체 게임은 한국어 독해가 필요하다'이다. Steam 영어 전체 지원 체크는 추가하지 않는다. 영문 상점 소개/그림은 게임 내 영어 번역 완료와 별개다.

## STOVE에서 받은 심의의 증빙

사용자 제공 STOVE Studio의 제품105282 심사 결과를 직접 읽었다. 자체심의등급분류, 12세 이용가, 폭력성, 등급번호 SGHS-SP-260821-0002, 심의 연결 빌드49279(출시전 최종 수정)다. 심사 완료일 표시는2026.08.21 12:54, 별도 등급분류일자 표시는2026.07.21 15:10으로 달라 공식 통지서에서 날짜를 확인해야 한다. 기본 화면·상세 화면에 필증 다운로드 버튼은 보이지 않았다. 실제 PDF를 발급받았거나 Steam 증빙 제출을 완료한 것은 아니다. 현재 v1.2.7과 심의 빌드 내용 비교 및 타 플랫폼 유통 통보 확인이 남아 있다.

확인할 자료: 등급분류번호, 결과 통지서 또는 필증(발급된 경우), 분류기관/일자/게임명/연령등급/내용정보, STOVE 상점 링크, 심의받은 버전과 현재 v1.2.7의 내용 차이.

게임산업진흥에 관한 법률 제21조의4는 자체등급분류 결과를 게임위 등급분류로 간주한다. 다른 자체등급분류사업자가 유통할 때의 예외가 있으며, 제21조의3 제2항 제2호는 자체등급분류사업자가 아닌 자를 통한 유통 시 게임위 통보를 규정한다. 적용 경로와 제출 방법은 실제 등급 문서와 현재 유통 조건을 가지고 STOVE/게임위에 확인한다. 내용 수정이나 계약 종료 후 변경도 확인해야 한다. 자동으로 새 유료 심의가 필요하다고 단정하지 않는다.

- 공식 법령 영문 본문 제21조의3/제21조의4: https://elaw.klri.re.kr/eng_mobile/viewer.do?hseq=69946&key=17&type=part
- 국가법령정보센터 한국어 조문은 이번 웹 도구에서 열리지 않았다. 최신 개별 적용 판단은 실제 문서와 담당기관 확인이 필요하다.
- Steam 공식 콘텐츠 설문: https://partner.steamgames.com/doc/gettingstarted/contentsurvey

Steam은 공식 발급 등급을 Ratings에 입력할 수 있다고 안내한다. STOVE 문서를 GRAC 직접 발급 필증으로 바꾸어 표시하지 않는다. 해당 번호의 입력 방식이 맞지 않으면 Steamworks 지원 문의에 실제 발급기관과 결과 문서를 제시해 확인한다. 확인한 자체등급번호를 GRAC 직접 발급 필증으로 오인하지 않으며, 이 세션에서 Steam 등급 입력/제출은 수행하지 않았다. Steam 콘텐츠 설문과 Valve 제품 심사는 한국 등급 증빙과 별개다.
