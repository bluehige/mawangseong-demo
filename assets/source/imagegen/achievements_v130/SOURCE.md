# Steam achievement icon provenance

- Generation model: GPT internal image generation
- Generated date: 2026-10-17
- Target version: v1.3.0

One GPT image_gen call per icon; no external generation services.
Original outputs are preserved byte-for-byte. Exact prompts and identity-reference paths: jobs.json.
The first prompt is also preserved verbatim in first_prompt.txt; later icons reference the original or a 256px same-set icon for frame style.
Postprocessing: RGB conversion, square downsample to 256x256 with Pillow LANCZOS, optimized PNG and JPEG quality 95/subsampling 0.
No local painting, background removal, recoloring, compositing, or replacement of icon artwork.
Opaque square icons were requested. Locked icons are generated by Steam; PIL grayscale contact sheets are preview-only.
Review sheets assemble thumbnails with labels OUTSIDE the icons; game and Steam integration are not performed.
Source receipt JSON records original hash/dimensions and generated file path.
