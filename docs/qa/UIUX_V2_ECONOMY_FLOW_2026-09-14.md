# Stage 02 자금 재확인·경제 흐름

작성 2026-09-14 · WORKSTREAM_ID UIUX-V2-ECONOMY-FLOW-20260914
작업은 9월13일 시작했으며 로컬 증거 폴더 날짜는 그대로 유지한다.

## 실제 수정

DAY 14 결산에서 자금이 부족하면 `campaign_stage_two_upgrade_funded`가 false로 남았다. DAY 15 날짜 수입 또는 되돌리기로 실제 보유량을 충족해도 기존 함수는 이 과거 플래그까지 요구하여 방어 시작을 계속 막았다.

- DAY 15처럼 자금 심사를 요구하는 일정이고 2장 진입을 완료했다면 **현재 보유량으로 재확인**한다.
- 기존 금화720·악명720 조건과 첫 승급/방어 시작의 다른 조건은 유지한다.
- 조회만으로 자원 차감·플래그 저장·성 해금은 일어나지 않는다.
- 이후 해당 보스전의 승리 결산에서 자금 확인과 해금 플래그를 함께 저장한다. 패배로는 해금하지 않는다.
- 기존 성 확장 심사는 보유 조건이며 이 경로에서 금화/악명을 결제하지 않는다. 새로운 차감이나 환급을 만들지 않았다.

재현 경계: DAY14 금화719·악명719 → 날짜 수입 금화32·악명15 → DAY15 금화751·악명734. 과거 조건 `funded && can_pay`는 false였지만 수정 후 재확인은 통과한다. 금화 또는 악명이 1 부족하면 계속 차단한다. 2장 진입 전·더 이른 날짜에도 새 재확인을 허용하지 않는다.

## 경제 기록의 범위

기본 웨이브를 모두 격퇴하고 승리했다는 **조건부 API 계산**으로 DAY1~15의 실제 비용·수입·보상·레벨업·승급·성 확장 함수를 호출했다. 전투 자동 완주가 아니며 전체 밸런스 PASS가 아니다.

시작 자원은 GameState.reset의 금화1245·마력320·식량18·악명620. 날짜 수입은 실제 advance_day를 한 번씩 호출했다. 가짜 잔고 지급, 강제 레벨 지정, 강제 승급/해금 플래그 설정 없이 아래 선택의 지출을 기록했다. 단, 별도의 경계 회귀 시험은 필요한 DAY14/15 상태와 잔고를 직접 설정한다.

이 선택에서는 실제 비용을 차감하고 기존 결과 해금 함수로 Stage02까지 연결된다. 그러나 스킬 마력 소비, 적 도난/도주, 패배, 원정·스토리 선택의 효과·필수 선택 절차, 추가 훈련·시설 지출을 포함하지 않는다. 따라서 위 잔고는 실전 여유 자금이나 필수 투자 전부를 반영한 잔고가 아니다. 공유/집중 경험치는 실제 함수로 누적하고 활약 EXP는0이다.
