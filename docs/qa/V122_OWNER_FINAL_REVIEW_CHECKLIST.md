# v1.2.2 사용자 최종검수 체크리스트

이 체크리스트는 사용자가 직접 실행하는 F1 수동 검수용이다. 현재 소스는 기술 버전 1.2.2로 준비됐지만 Windows·Web 후보 빌드, 해시, 태그, Release는 아직 만들지 않았다.

## 시작 전

- 작업 대상 SHA와 실행 환경(Godot/Windows/브라우저)을 기록한다.
- 기존 1.2.1 저장을 별도 복사해 원본을 보존한다.
- 새 게임용 저장과 기존 저장 이어하기용 저장을 분리한다.
- 오류가 나면 `DAY`, 화면, 캠페인 모드, 사용한 저장 출처를 함께 기록한다.

## 필수 경로

| 경로 | 확인 내용 | 결과 |
|---|---|---|
| 새 게임 DAY 1~5 | 온보딩, 방·시설 선택, 몬스터 배치, 지시 4종, 결과 원인 | 미검수 |
| 새 게임 DAY 6~30 | 관리일, 보스, 성장·승급, 저장·이어하기, 엔딩 | 미검수 |
| 1.2.1 중간 저장 | 이어하기, 다음 DAY 진입, 성장·시설 유지, 엔딩 도달 | 미검수 |
| 시설 중심 빌드 | 건설·업그레이드·무력화·수리·전투 기여 | 미검수 |
| 몬스터 성장 중심 빌드 | 배치·특화·승급·왕관 진화·결과 성장 | 미검수 |
| 명령 최소 사용 빌드 | 명령 없이도 진행 가능, 실패 원인 이해 가능 | 미검수 |
| Update 2 대표 경로 | 계약·회차 선택·E00~E11 | 미검수 |
| Update 3 대표 경로 | 전선·심장·합동기·연대기·E12~E16 | 미검수 |
| Update 4 대표 경로 | 지역·전초기지·상층·의회·왕관·E17~E22 | 미검수 |

## 화면·입력

- 1920×1080과 1366×768에서 타이틀·관리·몬스터·전투·결과 화면의 겹침과 잘림을 확인한다.
- 모바일 대표 흐름에서는 landscape 전환, 터치 대상, 최대 글꼴, 관리·전투 HUD를 확인한다.
- Windows 물리 환경에서 한국어 IME 조합 중 입력·Backspace·화면 전환을 확인한다.
- 모든 버튼을 실제로 눌러 dead click, 임시 문구, 비어 있는 결과, 잘못된 수치 설명이 없는지 확인한다.
- Update 4 지역 적 6종이 마젠타 배경 없이 정상 애니메이션으로 보이는지 확인한다.

## 저장·복구

- 관리 안전 화면에서 저장 후 이어하기가 같은 DAY·배치·시설·성장 상태를 복원하는지 확인한다.
- 전투 패배 뒤 재도전과 패배 수용이 서로 다른 결과를 남기는지 확인한다.
- 손상 저장 안내와 `.tmp`·`.bak` 복구가 기존 정상 저장을 덮어쓰지 않는지 확인한다.
- 1.2.1 저장 파일의 원본 hash와 수정 시각을 검수 전후 비교한다.

## 피드백 형식

문제가 있으면 아래 형식으로 전달한다.

```text
V122_OWNER_QA_FAIL
severity: P0 | P1 | P2 | P3
source_sha:
environment:
day_and_screen:
save_origin: new | v1.2.1 | v1.2.2
steps:
expected:
actual:
attachments:
```

모든 필수 경로를 통과하면 아래처럼 전달한다.

```text
V122_OWNER_QA_PASS
source_sha:
completed_paths:
remaining_notes:
```

사용자 PASS 뒤에만 동일 SHA에서 Full 검증, 후보 export, Windows·Web hash 고정, 태그·Release·배포 단계로 진행한다.
