## 통합 판정

**GRAPHIC_DIRECTION_REVISION_REQUIRED**

현재 그래픽은 소재가 부족한 상태가 아니다. 타이틀 동굴, 왕좌실, 방별 랜드마크, 대화 초상화, 고딕 프레임에는 이미 분명한 브랜드가 있다. 문제는 이 좋은 자산들이 실제 관리·전투 화면에서 하나의 규칙으로 합성되지 않는다는 점이다.

성 지도는 화면 전체의 주인공이 아니라 검은 앱 셸 안에 삽입된 고정 크기 이미지처럼 보인다. 황금색은 장식·경로·선택·튜토리얼·버튼에 동시에 사용돼 현재 판단 지점이라는 의미를 잃는다. 캐릭터는 이소메트릭 배경과 투영·채도·광원·접지 규칙이 달라 스티커처럼 뜨며, 전투에서는 링·이름·체력바·VFX가 실루엣을 덮는다. 1280×720에서는 이 구성을 통째로 축소해 장식은 남고 텍스트와 캐릭터 세부는 무너진다.

따라서 새 그래픽을 더 만드는 것보다 먼저 **레이아웃, 색 역할, 환경·캐릭터 합성 규칙을 한 장의 아트 바이블로 고정**해야 한다.

## 잘된 부분

### 1. 타이틀은 현재 제품에서 가장 완성도 높은 포스터형 화면이다

- 동굴 중앙의 차분한 공간이 제목과 새 게임을 자연스럽게 받친다.
- 좌우 소품과 보라 수정이 신입 마왕의 임시 성이라는 설정을 설명한다.
- 어두운 암부, 제한된 보라, 단일 주 행동의 관계는 유지할 가치가 있다.

### 2. 대화용 왕좌실은 재질·조명·공간 서사가 좋다

- 검붉은 직물, 황동, 보라 화염이 반복돼 세계관이 즉시 읽힌다.
- 골딘 초상화의 따뜻한 측광은 왕좌실과 잘 맞고 바티도 보라 외곽광으로 충분히 분리된다.
- 대화 화면은 성 배경과 인물이 서로를 강화하는 현재의 좋은 기준 화면이다.

### 3. 방별 랜드마크 실루엣은 기능 전달력이 높다

- 입구, 회복실, 보물실, 병영, 왕좌의 형태와 재질이 서로 다르다.
- 텍스트를 읽기 전에도 방의 성격을 파악할 수 있다.
- 성 지도를 화면의 주인공으로 확대할 충분한 시각 자산이 이미 있다.

### 4. 핵심 캐릭터 원본의 알파 경계는 깨끗하다

- 밝은 매트 테두리나 사각 배경 같은 기술적 컷아웃 오류는 보이지 않는다.
- 심각한 AI형 해부 왜곡도 표시 크기에서 발견되지 않았다.
- 문제는 개별 이미지 품질이 아니라 공통 투영·광원·채도·접지 규칙의 부재다.

## 중복 제거 핵심 디자인 게이트

### G1. 성 지도를 full-canvas 주 작업면으로 되돌린다

- 현재: 1920 화면 중앙의 고정 폭 지도, 큰 검은 여백, 우측 패널, 이중 하단 바가 성을 밀어낸다.
- 영향: 성이 실제 공간이 아니라 검은 UI 위에 붙인 이미지처럼 보인다.
- 방향:
  - 상단은 얇은 상태 레일로 압축한다.
  - 선택 정보는 내용 기반 우측 drawer로 제한한다.
  - 수비대는 낮은 높이의 compact rail로 줄인다.
  - 지도 가장자리는 암벽·보라 안개·불규칙 마스크로 화면 배경까지 이어 준다.

### G2. 밝은 황금색의 역할을 현재 판단 대상으로 제한한다

- 현재: 금색이 프레임, 자원, DAY, 방 경계, 경로, 버튼, 튜토리얼, 선택 상태에 모두 쓰인다.
- 영향: 어디를 봐야 하는지 알려 주는 신호가 화면 전체의 기본 윤곽선으로 소진된다.
- 방향:
  - 정적 장식은 어두운 황동으로 낮춘다.
  - 일반 경로는 저채도 보라 회색 또는 철색으로 바꾼다.
  - 밝은 황금은 한 화면에서 현재 선택 후보 또는 주 행동 하나에만 사용한다.
  - 보라는 마력·특수 상태, 적갈색은 위험, 청회색은 정보처럼 역할을 분리한다.

### G3. 환경과 캐릭터의 공통 아트 바이블을 만든다

- 현재: 회화형 방, 픽셀아트 왕좌, 카툰 슬라임, 반실사 고블린, 애니메이션형 임프·용사가 한 화면에 섞인다.
- 영향: 캐릭터와 방이 같은 장소의 존재가 아니라 서로 다른 자산을 겹친 콜라주처럼 보인다.
- 아트 바이블 고정값:
  - 이소메트릭 카메라 30~35도 하향
  - 공통 발 기준선과 실제 실루엣 높이
  - 상좌측 온광과 보라 환경 반사광
  - 외곽선 두께와 채도 상한
  - 낮고 부드러운 접촉 그림자
  - 방 재질의 선 굵기·텍스처 주파수·황동 반사 규칙

### G4. Stage 01 왕좌와 방·복도 접합부를 우선 정리한다

- 현재: 왕좌는 다른 방과 달리 픽셀아트이며 방 받침판과 복도의 문턱·타일 방향·명암이 끊긴다.
- 영향: 가장 중요한 목적지가 가장 큰 화풍 이탈점이고, 성 구조가 연결 공간보다 모듈 섬처럼 보인다.
- 방향:
  - 왕좌를 입구·회복실·보물실의 회화형 렌더링 언어로 다시 제작한다.
  - 방향별 문턱·계단·파손석 transition tile을 만든다.
  - 공통 환경 폐색 그림자와 불규칙 맵 가장자리 마스크를 적용한다.
  - Stage 01~04 대표 방 contact sheet를 먼저 승인한 뒤 개별 제작을 진행한다.

### G5. 전투는 액터 실루엣을 최우선으로 다시 합성한다

- 현재: 캐릭터, 진영 링, 이름, 체력바, 피해 숫자, 방 효과, 보라 VFX가 같은 좌표에 겹친다.
- 영향: 누가 무엇을 하는지보다 색 덩어리와 텍스트가 먼저 보인다.
- 방향:
  - 렌더 순서를 `바닥 → 접촉 그림자 → 선택 링 → 캐릭터 → VFX → 이름·체력 → 경고`로 고정한다.
  - 미선택 유닛 링은 상시 표시하지 않는다.
  - 이름·체력바는 화면 좌표 충돌 회피 규칙을 사용한다.
  - 일반 VFX의 최대 휘도·면적·동시 노출 수를 제한한다.
  - 적·아군은 적록색만이 아니라 배지 형상·선 패턴·얇은 림라이트로 구분한다.

### G6. 1280×720은 1920 화면의 단순 축소판으로 만들지 않는다

- 현재: 장식 프레임, 설명문, 우측 inspector, 하단 명령이 동일 비율로 축소된다.
- 영향: 장식은 노이즈로 남고 한글 본문·상태문과 캐릭터 재질은 읽기 크기 아래로 내려간다.
- 방향:
  - 1280 전용 compact density를 만든다.
  - 상단은 아이콘+값 중심, inspector는 핵심 정보 우선, 하단은 현재 행동 중심으로 줄인다.
  - 작은 버튼은 단순 프레임 자산을 사용한다.
  - 본문 최소 크기와 대비를 고정하고 설명 길이를 줄인다.

### G7. 결과·튜토리얼도 성의 세계 안에 남긴다

- 현재: 결과는 검은 카드 대시보드가 되고, 튜토리얼은 평면 레몬색 상자·화살표·전체 dim으로 성을 덮는다.
- 영향: 플레이의 보상 순간과 학습 순간마다 제품의 미감이 중단된다.
- 방향:
  - 결과는 직전 전장 또는 왕좌실을 낮은 명도로 유지한다.
  - 승리 문장과 성 crest를 주 시각물로 두고 수치는 연속 목록으로 압축한다.
  - 튜토리얼은 국소 마스킹, 짧은 연결선, 기존 황동·보라 재질을 사용한다.
  - 밝은 황금 표식은 대상 주변 halo 또는 pulse 하나로 제한한다.

## 화면별 처리 우선순위

1. **관리·배치:** full-canvas 지도, 금색 경로 절제, compact 수비대, 내용 기반 inspector
2. **전투:** 캐릭터 접지, 링·라벨·VFX 시각 예산, 적록 이외의 진영 신호
3. **전투 결과:** 성 배경 복원, 카드 축소, 승리 보상 이미지 강화
4. **DAY 1 캐릭터·Stage 01 왕좌:** 공통 아트 바이블에 맞춘 대표 자산 교체
5. **1280×720:** 전용 밀도와 단순 프레임
6. **튜토리얼·등록:** 중첩 테두리와 평면 노란 안내를 세계관 재질에 통합
7. **타이틀·대화:** 현재 강점을 유지하고 비네팅·초상 크롭만 마지막에 다듬기

## 구현 전 승인해야 할 한 장

그래픽 수정에 들어가기 전에 다음 내용을 한 장의 comparison board로 승인받아야 한다.

- 1920 관리 화면 full-canvas 와이어프레임
- 1280 compact 와이어프레임
- UI 프레임 3등급: 주 행동 / 전술 선택 / 상태·유틸리티
- 팔레트 역할: 암부 / 패널 / 황동 / 마력 보라 / 판단 황금 / 위험 적갈 / 정보 청회색
- Stage 01 방 5종과 왕좌의 같은 크기 contact sheet
- 슬라임·고블린·임프·수습 용사의 같은 각도·광원·크기 비교
- 접촉 그림자, 선택 링, 이름·체력바, 일반 VFX의 합성 순서 예시

이 한 장을 승인하지 않고 개별 자산부터 교체하면 현재의 화풍 편차가 다른 형태로 반복될 가능성이 높다.
