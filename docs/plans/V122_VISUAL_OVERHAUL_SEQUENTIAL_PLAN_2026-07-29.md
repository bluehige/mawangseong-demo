# v1.2.2 순차 UI·그래픽 개편 확정 계획

## 1. 문서 목적

이 문서는 2026-07-29까지의 UI·전투·재미·그래픽 디자인 검수 결과와 사용자 결정을 하나의 실행 기준으로 고정한다.

- 한꺼번에 전 화면을 수정하지 않는다.
- 공통 기반을 먼저 만든 뒤 화면을 하나씩 수정한다.
- 각 단계는 `브리핑 → 필요한 시안/기준표 → 승인 → 해당 단계만 구현 → 최소 확인` 순서로 진행한다.
- 전체 플레이 검수, 전체 회귀 검수, 최종 판정은 마지막 통합 단계에서 한 번 진행한다.
- Windows판을 출시 기준으로 삼는다.
- 데스크톱 웹은 외부 테스트용 빌드이며 출시판으로 취급하지 않는다.
- 모바일 웹 UI와 빌드는 이번 범위에서 제외한다.

## 3. 확정된 제품·디자인 결정

### 3.1 화면과 레이아웃

- 성 지도와 전장은 `Full-canvas`를 기본으로 한다.
- 지도·전장을 검은 상시 패널로 덮지 않는다.
- 선택 상세는 필요할 때만 나타나는 context drawer로 제공한다.
- 1920×1080은 표준 레이아웃이다.
- 1366×768과 1280×720은 단순 축소가 아닌 전용 Compact 레이아웃을 사용한다.
- 환경설정의 레이아웃 모드는 `자동 / 1920 표준 / Compact`다.
- `자동`은 창 너비 1440 미만에서 Compact, 그 이상에서 표준을 선택한다.
- 사용자가 표준 또는 Compact를 강제 선택하면 해당 값을 기기에 저장한다.

### 3.2 UI 시각 체계

- 어두운 판타지 정체성은 유지하되 절제된 고딕 UI로 정리한다.
- 금색 장식 프레임은 화면당 주 행동 하나와 현재 최우선 강조에만 사용한다.
- 일반 버튼은 얇은 선과 어두운 면을 사용한다.
- 패널은 두꺼운 액자보다 반투명 면과 구분선을 우선한다.
- 시설·몬스터 카드는 실제 선택 또는 drag 대상일 때만 카드 형태를 사용한다.
- 지도, 캐릭터, 시설 그래픽이 UI 장식보다 먼저 읽혀야 한다.
- 색상 하나로 상태를 전달하지 않고 아이콘, 외곽선, 문구를 병행한다.

### 3.3 배경과 캐릭터 아트

- 기존 쿼터뷰 픽셀아트를 기준 스타일로 고정한다.
- 모든 자산을 다시 만들지 않고 기준에서 벗어난 자산만 선별 교체한다.
- 공통 기준표에 카메라 각도, 캐릭터 크기, 좌상단 광원, 우하단 그림자, 채도, 외곽선, 접지 그림자를 기록한다.
- Stage 01 왕좌와 DAY 1 핵심 캐릭터 자산은 기준 불일치 시 교체할 수 있다.
- 배치·전투 레이어는 `바닥 → 접지 그림자 → 선택 표시 → 캐릭터 → 일반 VFX → 이름·체력 → 긴급 경고` 순서를 기준으로 재정리한다.

## 4. 환경설정 확정 사양

### 4.1 접근 위치와 페이지 구조

- 타이틀 화면에서 `환경설정`으로 진입한다.
- 배치·전투 중에는 `ESC → 일시정지 메뉴 → 환경설정`으로 진입한다.
- 전투 중 환경설정을 열면 전투를 완전히 일시정지한다.
- 닫으면 진입했던 화면으로 돌아간다.
- 화면마다 환경설정 버튼을 상시 노출하지 않는다.
- 작은 중앙 팝업이 아닌 독립된 전체 화면 페이지로 만든다.
- 왼쪽 카테고리, 중앙 설정 내용, 오른쪽 실시간 미리보기, 하단 적용 영역을 사용한다.
- 카테고리는 `일반 / 화면 / 그래픽·접근성 / 오디오 / 조작` 5개다.

### 4.2 적용 규칙

- 음량, 밝기, UI 크기는 조절 즉시 미리보기한다.
- 언어, 레이아웃, 키 설정은 `적용`으로 확정한다.
- 해상도와 창 모드는 적용 후 15초 안에 확인하지 않으면 이전 값으로 자동 복구한다.
- `취소`는 페이지를 열기 전 값으로 되돌린다.
- 기본값 복원은 카테고리별 복원과 전체 복원을 분리한다.
- 설정은 캠페인 저장과 분리해 기기별 `user://settings.cfg`에 저장한다.

### 4.3 일반

- 실제 지원 언어는 `한국어 / English` 두 개다.
- 최초 기본값은 운영체제 언어를 감지한다.
- 미지원 언어는 한국어로 대체한다.
- 번역 구조는 일본어·중국어 등 후속 언어를 추가할 수 있게 만든다.
- 튜토리얼 안내 수준은 `전체 / 핵심만 / 끄기`다.
- 최초 플레이 기본값은 `전체`다.
- 안내 기록 초기화는 본 말풍선과 도움말만 초기화하고 캠페인 저장은 건드리지 않는다.
- 튜토리얼 다시 하기는 현재 캠페인과 분리된 연습 흐름으로 시작한다.
- 스토리 이벤트와 필수 선택은 튜토리얼을 꺼도 유지한다.
- 기본 전투 속도는 마지막 선택값을 저장한다.
- 고속 배율이 잠긴 구간은 x1로 제한하고, 제한 해제 뒤 저장된 배속으로 복귀한다.
- 해금하지 않은 배속은 환경설정에서 선택할 수 없다.

### 4.4 화면

- 레이아웃: `자동 / 1920 표준 / Compact`
- UI·글자 크기
- Windows 출시판:
  - 창 모드
  - 테두리 없는 전체화면
  - 전체화면
  - 해상도
  - 수직동기화
  - 최대 FPS
- 데스크톱 웹 테스트판:
  - 브라우저 전체화면
  - 레이아웃 모드
- 플랫폼에서 작동하지 않는 옵션은 비활성화해서 남기지 않고 숨긴다.

### 4.5 그래픽·접근성

- 색상 프리셋: `일반 / 적록 보조 / 청황 보조 / 고대비`
- 전체 화면 색 필터에만 의존하지 않는다.
- 아군, 적군, 선택, 위험 상태는 색상과 서로 다른 아이콘·외곽선을 함께 사용한다.
- 튜토리얼 강조는 노란색만 쓰지 않고 테두리 애니메이션과 기호를 함께 사용한다.
- 배경 원화 색감은 가능한 한 유지한다.
- 화면 흔들림: 0~100%
- 전투 이펙트 강도: 낮음/보통/높음
- 섬광 감소: 켜기/끄기
- UI 애니메이션 감소: 켜기/끄기
- 낮춤 설정에서도 피격, 위험, 명령 성공 여부는 아이콘과 소리로 전달한다.

### 4.6 오디오

- 마스터 음량
- 음악 음량
- 효과음 음량
- 실제 음성 자산과 재생 계층이 생기기 전에는 음성 음량을 UI에 표시하지 않는다.

### 4.7 조작

- 사용자 기능만 재지정한다.
- 대상 기능:
  - 일시정지
  - 다음 몬스터 선택
  - 대화 진행
  - 마왕성 핵심기
  - 합동기 1
  - 합동기 2
  - 확대
  - 축소
  - 명령 취소
- 기능마다 기본키와 보조키 두 개를 지원한다.
- 키 중복 시 기존 배정과 교환할지 확인한다.
- ESC와 기본 좌·우 클릭은 안전 조작으로 고정한다.
- F3~F9 개발용 디버그 키는 설정에서 숨기고 재지정하지 않는다.

## 6. 순차 구현 계획

현재 진행 상태:

- 0단계: 화면 계약 문서화 완료
- 1단계: 설정 저장·전체 화면 shell·레이아웃/언어/입력 기반 완료
- 2단계: Standard/Compact 관리·배치 레이아웃 구현 완료, 사용자 시각 확인 대기
- 3단계: 공통 색 토큰·버튼 3등급·상태 언어·상단 상태 레일 구현 완료, 사용자 시각 확인 대기
- 4단계: Stage 01 실제 렌더·walkable 구조 조사와 대표 자산 비교 보드 완료
- 5단계: DAY 1 캐릭터 접지·선택 표시·정보 노출 계층 완료
- 6단계: 1920/1366/1280 전투 HUD와 네 제한 명령 계층 완료
- 7단계: 캐릭터·체력·선택·VFX·경고 시각 레이어 계약 완료
- 8단계: 결과 UI의 실제 배치·지침·기여도 인과 연결 완료
- 9단계: DAY 1 곱 전열·후열 선택, 반응형 배치, 실제 교전 차이 확인 완료
- 10단계 1차: 튜토리얼 안내 수준 `전체/핵심만/끄기`를 기기 설정·이름 등록·런타임 안내에 연결하고, 등록 도움말과 실제 카드 강조를 비차단형으로 수정 완료
- 10단계 2차: 설정·이름 등록·DAY 1~3 튜토리얼의 한국어/영어 키·카탈로그와 일반 설정 언어 선택기 연결 완료
- 10단계 3차: 말풍선·도움말 기록을 기기 설정으로 분리하고, 현재 locale·안내 수준·기존 단계 ID를 사용하는 캠페인 비의존 DAY 1~3 연습 흐름 연결 완료
