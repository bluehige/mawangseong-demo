# 제품 1.2.2 릴리스 노트

작성일: 2026-08-06

화면 표시: `1.2`

기술 SemVer: `1.2.2`

## 핵심 변경

- 기존 1.2.1의 DAY 1~30 캠페인과 저장 구조를 유지하면서 건물 호환성, 공간 배치, 전투 규칙, 성장·저장 진행을 하나의 제품 흐름으로 통합했다.
- DAY 1~5 온보딩과 DAY 6~30 본편 대사를 실제 런타임에 연결하고 후반 전선·결전·엔딩까지 진행 상태가 이어지도록 보강했다.
- 전체 30일 밸런스 모델과 콘텐츠 호환성 검사를 추가해 해금, 업그레이드, 적 편성 및 결산 흐름을 고정했다.
- 수비대 경로 선택과 전투 화면 갱신 비용을 보정해 길 막힘과 불필요한 재그리기를 줄였다.

## 던전과 UI

- 쿼터뷰 통로, 도로, 구조벽을 통합하고 앞쪽 벽은 반투명하게 유지해 통로의 입체감과 캐릭터 가시성을 함께 확보했다.
- 바닥, 유닛, 전면 장식과 구조벽의 깊이 순서를 바로잡아 유닛이 바닥 뒤로 숨거나 벽 위에 부자연스럽게 뜨는 문제를 수정했다.
- 관리·전투·결산 화면의 정보 구조를 단순화하고 방 지침 선택 글자를 20px, 버튼 높이를 46px로 확대했다.
- 함정 유도 안내, 전투 대상 우선순위와 사용자 조작 피드백을 실제 동작과 일치하도록 정리했다.

## 그래픽과 오디오

- 지역 적과 계약 몬스터의 전투 스프라이트, 던전 구조벽·도로·문턱 자산을 정식 런타임에 연결했다.
- 스테이지 1~4 환경음, 전투 타격·결과음, 발소리, UI 효과음과 주요 음악을 추가하고 오디오 라우팅·동시 재생 계약을 검증했다.
- 변경 이미지 152개를 유효한 생성 출처 문서 19개에 각각 한 번씩 연결해 누락·중복·존재하지 않는 경로를 모두 제거했다.

## 호환성과 배포

- 기존 1.2 저장 경로와 핵심 저장 스키마를 유지하며 이전 저장을 이어서 플레이할 수 있다.
- 게임 화면에는 계속 `1.2`로 표시하고 프로젝트·Windows 파일·태그에는 `1.2.2`를 사용한다.
- 정식 Web 및 Windows 패키지는 `v1.2.2` GitHub Release에 보관한다.
- Windows 실행 파일은 코드 서명 인증서가 없어 서명되지 않았다.

## 검증

- 정식 출시 게이트는 Full core verification 156개, 독립 통합 검수 P1/P2/P3 0건, Windows release export·1280×720 부팅·ZIP 해시와 Web `build-manifest.json` 검증을 모두 통과한 태그 산출물에만 적용한다.
- 던전 구조벽과 실제 캐릭터 불투명 픽셀의 겹침, 위·아래 유닛의 Y 깊이, 방 지침 강조·목록·시설 패널의 1280×720 무겹침을 실제 렌더로 확인했다.
