# 마왕성 v1.2.6 릴리스 노트

`v1.2.6`은 화면 표시 `1.2`와 기존 저장 호환성을 유지하면서 전투 지휘 신뢰성, 몬스터 AI, 방별 지침, 초반 건설 흐름과 방 이름표 가독성을 보강하는 품질 패치다.

## 주요 변경

- 집결·집중·비상 후퇴를 상시 핵심 명령 3개로 정리하고 시설 발동은 선택한 방의 문맥 행동으로 이동했다.
- 명령 수락과 거부를 대상 근처 효과, 짧은 비모달 알림과 구분되는 효과음으로 표시한다.
- 유효한 전술 명령은 평상시 AI보다 우선하며, 0.3초 안에 수행할 수 없으면 대기 이유와 가능한 복구 행동을 알린다.
- 도둑 사냥꾼, 금고 수호자와 역할별 몬스터가 가까운 일반 적보다 자신의 핵심 위협을 먼저 처리한다.
- 방별 지침을 명령·왕좌 긴급 대응 다음, 자율 역할 AI보다 먼저 평가한다.
- 입구 봉쇄는 입구에 배치된 슬라임·곱·임프·후반 동료가 모두 수행하며 HUD의 적용 지침과 실제 행동이 일치한다.
- 반대 전선 유닛은 다른 방 지침에 끌려가지 않고 자신의 배치와 역할을 유지한다.
- 빈 건설 슬롯을 `+ 건설 가능`으로 표시하고 지도 클릭을 `미리보기 → 명시적 확정 → 1회 비용 차감`으로 통일했다.
- 보물 보관실과 같은 전선의 추천 시설과 실제 효과를 시설 목록에서 바로 확인할 수 있다.
- 방 이름표와 방 지침 배지를 전면 소품·벽보다 높은 월드 오버레이에 표시해 그림에 가려지지 않게 했다.
- Windows PC를 품질 기준으로 유지하며 모바일 터치 UI도 동일한 핵심 명령 3개를 사용한다.

## 호환성

- 사용자 화면 버전은 기존 정책대로 `1.2`로 표시한다.
- 프로젝트·Windows 파일·manifest 버전은 `1.2.6` / `1.2.6.0`이다.
- 기존 v1.2 저장 경로와 저장 형식을 변경하지 않는다.
- 기존 `v1.2.5` 태그와 Release는 이동하거나 교체하지 않는다.

## 출시 산출물

- Windows: `MawangCastle-v1.2.6-Windows.zip`
- Web: `mawangseong-v1.2.6-web.zip`
- 체크섬: `SHA256SUMS.txt`
- Git 태그: `v1.2.6`

정식 자산은 최종 `main` merge SHA의 Full 검증, Windows 정식 export·manifest·부팅, Web manifest 검증을 모두 통과한 동일 소스에서 생성한다. 사용자와 지인의 후속 플레이 피드백은 기존 완료 기록을 소급 변경하지 않고 다음 개선 주기로 접수한다.
