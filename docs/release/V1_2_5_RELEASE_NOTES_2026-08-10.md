# 마왕성 v1.2.5 릴리스 노트

출시일: 2026-08-10

`v1.2.5`는 `v1.2.4`의 저장 호환성과 화면 표시 `1.2`를 유지하면서 그래픽, 패배 결산, DAY 29 스토리 흐름과 핵심 UI 가독성을 마무리한 정식 품질 패치다.

## 주요 변경

- Stage 02 성곽, Stage 03 방어 요새, Stage 04 최종 성채에 전용 배경과 통로 그래픽을 추가했다.
- 전투 유닛이 바닥 위에 표시되고 전면 벽에는 반투명하게 가려지는 깊이 규칙을 전 단계에서 유지했다.
- 패배 시 전투 중 얻은 금화·마나·식량·악명과 EXP·유대·레벨 상승이 전투 시작 상태로 되돌아가도록 고쳤다.
- DAY 29의 긴 대사를 세 구간으로 나누고, 세 최후 선언과 Update 3 전선별 결전 전야 반응이 실제 진행에서 출력되게 연결했다.
- 패배 결산에 다음 재도전에서 바꿀 행동 한 가지를 표시한다.
- 1280×720 전투 HUD의 보조 정보, 지침 목록과 결과 화면의 필수 집중 성장 선택을 확대했다.
- 내부 역할명·축약어, 잘린 문장과 그대로 노출되던 Markdown 백틱을 자연스러운 한국어 문구로 정리했다.
- 작은 피해 숫자의 시작 배율과 펼친 선택 목록의 사용자 글자 배율 적용을 보정했다.

## 호환성

- 기존 사용자 데이터 폴더와 저장 형식은 유지된다.
- 이전 `v1.2.0`~`v1.2.4` 태그와 Release는 변경하지 않는다.
- Windows 정식판과 Web 직접 플레이판은 같은 `v1.2.5` 태그 소스에서 생성한다.

## 정식 산출물

- Windows: `MawangCastle-v1.2.5-Windows.zip`
- Web: `mawangseong-v1.2.5-web.zip`
- Git 태그: `v1.2.5`
- GitHub Release: `마왕성 v1.2.5`
- Web 직접 플레이: <https://bluehige.github.io/mawangseong-demo/web_Demo/>

정식 출시 판정은 태그 대상 SHA의 Full 핵심 검증, Windows/Web export, 빌드 manifest 검증과 공개 Web 부팅이 모두 통과한 뒤 확정한다.
