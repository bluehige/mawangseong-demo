# 제품 1.2.3 릴리스 노트

작성일: 2026-08-06

화면 표시: `1.2`

기술 SemVer: `1.2.3`

## 핵심 변경

- `1.2.2`의 게임 기능·밸런스·그래픽·오디오·저장 호환성을 그대로 유지한다.
- Windows와 Linux에서 정식 검증 카탈로그의 줄바꿈을 LF로 고정해 태그 원본과 Release 증빙의 바이트가 항상 같도록 보정했다.
- Full 검증 보고서가 작업 파일이 아니라 현재 커밋의 Git blob을 바이너리 스트림으로 해시하도록 복원했다.
- 저장소 CI가 카탈로그 체크아웃 바이트, Git blob 해시와 LF 속성을 직접 검사해 같은 배포 차단 결함의 재발을 막는다.

## 배포

- `v1.2.2` 태그와 기존 Release 자산은 감사 기록으로 이동·삭제·교체하지 않는다.
- 정식 Web 및 Windows 패키지는 새 `v1.2.3` GitHub Release에 보관한다.
- Windows 실행 파일은 코드 서명 인증서가 없어 서명되지 않았다.

## 검증

- 정식 출시 게이트는 최종 `main` SHA의 Full core verification, 독립 통합 검수 P1/P2/P3 0건, Web 매니페스트 원본·ZIP 재검증, Windows export·1280×720 부팅·ZIP 해시와 Pages 공개 부팅 확인을 모두 통과해야 한다.
