IA §7 및 §8 U5-4의 실제 전투 HUD를 스타일 B로 교체한다. 정책과 즉시 행동 분리, 유닛 선택→명령/스킬, 정지/배속/컷신/층 이동, 터치 상세의 고정 조작 비침범, 세 언어 표시 및 튜토리얼 대상 ID를 검증한다.

새 이미지, 명령 비용/대상/효과, 스킬 효과/자동 AI/밸런스, 저장 스키마, 버전/스토리, 던전 미술·지도 구조, 출시 및 다음 U5 단계는 제외했다. 새 GPU/FPS 장시간 측정이나 전체 회귀를 추론하지 않았다.

## 3. 완료한 작업

- HUDController의 지정 빌더들은 새 CombatWorkspaceUI로 연결한다. ManagementWorkspaceUI의 kit_panel/kit_button/kit_copy/kit_flow와 U4 UIKit/KitSurface/StyleB를 재사용하며 공통 키트·관리 화면은 수정하지 않는다.
- 상단에는 DAY/왕좌 HP/명령 포인트/실제 마력/남은 적 수와 전투 기록·메뉴 아이콘을 둔다. 남은 적은 현재 살아 있는 적과 기존 스케줄의 미출현 수를 읽는다. 방어 진행·실제 위협 상세는 툴팁에 남긴다.
- 성 전체/이 방의 지속 지침은 전술 버튼으로 펼친다. 기존 DAY1 사수 잠금과 지침 콜백을 유지한다. 시설 가동은 지침이 아니라 명령 줄의 즉시 행동이다.
- 하단에는 기존 집결/집중/비상 후퇴의 포인트·활성/재사용 대기, 선택 동료의 수동 스킬·실제 마력 비용/대기, 해금된 심장·최대 두 합동기를 연결한다. 항목이 많으면 해당 행동 줄만 가로 스크롤하며 고정 배속/정지와 분리한다. 삼색 왕관 핀의 정책은 선택 상세, 기존 수동 발동은 행동 줄로 연결한다. 자동 사용·효과·유효성 판정은 기존 서비스가 담당한다.
- 우측 선택 상세는 마우스/터치 모두 가용 높이를 제한하고 긴 내용만 스크롤한다. 닫기는 스크롤 밖에 두며 실제 번역 버튼 최소 크기를 예약한다. 배속 1/1.5/2/3과 정지/재개는 고정 위치를 유지한다.
- GameRoot의 전투 포인터 판정을 옛 고정 사각형 대신 실제 표시 컨트롤/스크롤 경계로 연결했다. 새 전투 메뉴와 겹치던 공통 메뉴는 전투에서 중복 생성하지 않고 기존 CommonGameMenuButton 튜토리얼 ID를 새 버튼에 별칭 등록한다. BossHpBar, GLOBAL_DIRECTIVE_DEFEND, V122_COMMAND_FOCUS/FALLBACK, 시설·수동 스킬·핀·층·3배속 ID를 유지했다.
- 전투 기록은 기존 정지 소유자의 상태를 보관해 닫을 때 복원한다. 메뉴의 기존 interrupt("menu")와 이전 정지 복원 절차는 유지했다.
- 컷신은 CanvasLayer 40으로 분리한다. 평소 HUD/상세/배속/층/지원·명령 알림은 숨겨 원래 가시성을 복원한다. 컷신 자체 스킵과 메뉴만 입력을 받으며 메뉴는 기존 중단 경로를 호출한다. 해당 실제 피해 숫자는 같은 컷신 Canvas로 옮겨 기존 월드 좌표·카메라 변환을 보존하고 종료 전에 숫자 풀의 원래 부모로 돌린다. 효과 1회 commit/기존 재개 시점은 유지한다.
- 컷신 동안 보류한 지원 성과 본문은 전투 기록에 보관하고 종료 후 짧은 요약으로 표시한다. 기존 전투 대화의 HUD 숨김/복원 주체는 StoryDialoguePresenter를 그대로 사용한다.
- 층 버튼은 현재 층을 강조한다. 숨은 층 경보를 상단/층/선택 상세와 겹치지 않는 곳에 배치하고 기존 고대비·음량·요약 설정을 보존했다. 다른 층으로 이동하면 해당 층에 속하지 않는 선택만 해제한다.

1. 큰 전술 헤더/선택 스킬 줄/명령 줄을 **정책 칩 2개 한 줄 + 즉시 행동 정사각형 한 줄**로 정리했다. 칩은 실제 성 전체/선택 방 정책을 읽고, 기본 방 정책은 짧게 ‘기본’으로 표시한다. DAY1 사수 잠금과 기존 정책 선택기를 유지한다.
2. 집결/집중/비상 후퇴/선택 스킬/통로 막기/합동기는 기존 핸들러에 연결한다. 마우스 행동은 184×184, 터치는 196×196 논리 픽셀이다. 명령 CP 1/1/2는 계속 표시하며 대기·발동 시간은 툴팁으로 옮겼다. 실제 스킬 마력/대기는 기존 계산을 읽는다. 잠금/비활성은 흐린 그림과 자물쇠로 표시한다. 명령의 부족/재사용 거절 피드백은 기존처럼 클릭 가능하게 보존한다. 미장착 합동기는 효과 없는 잠금 타일로만 표시한다.
3. 상단 오른쪽은 커진 **설정·메뉴 / 저장 / 전투 기록** 아이콘 3개다. 설정은 기존 메뉴를 열며 저장은 기존 메뉴/저장 시도 경로를 사용한다. 전투 중 저장 불가·마지막 체크포인트 안내가 그대로 표시되고 저장 가능 조건/파일/스키마는 바꾸지 않는다. 기록의 정지/복원 계약도 유지한다.
4. 선택 유닛 요약은 큰 기존 초상, 이름, 실시간 HP 바와 수치, 고정 대표 스킬을 먼저 표시한다. 스탯/위치/상태/삼색 정책은 ‘상세 보기’ 아래에서 펼쳐 스크롤한다. 패널 폭을 마우스360/터치460으로 줄였고 닫기·대표 스킬·상세 토글이 패널/하단 조작 경계를 넘지 않음을 검사했다.
