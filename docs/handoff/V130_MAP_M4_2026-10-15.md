## 3. 완료한 작업

### A. 헤드 검수 보정

1. 자동 생성된 **기존 길 칸** 위에 밝은 돌 포장을 그린다. 기존 `torchlit_flagstone`을 재사용하고 밝은 바탕·줄눈을 더했다. auto_roads·tile_walk_cells·문·연결·전투 경로는 그대로다.
2. 방·길 아래에 하나의 불투명 석조 바닥면과 앞/옆 낮은 경계·기단을 그린다. 방이 떨어진 섬처럼 보이던 빈 공간을 연결한다. 미해금 확장은 어두운 예약 띠와 잠금 표시로 구분한다. 시각 바닥을 이동 가능 칸에 추가하지 않는다.
3. 뒷벽을 부지 폭과 같은 경계에 맞춰 종료한다. 연결된 석조 벽, 높이가 조금 다른 덮개, 엇갈린 줄눈, 기둥·기존 화로 간격으로 반복감을 줄인다. 부지 밖까지 큰 블록을 나열하던 코드를 제거했다.
4. 관리 기본 화면/지도 전체는 방 배치의 일부 대신 **부지 전체와 뒷벽**의 공통 경계로 맞춘다. 도구 펼침 상태를 먼저 적용하고 등급·부지 크기·해상도 변화에 맞춰 중앙 정렬한다. 관전 카메라는 수정하지 않았다.
5. `Stage 02 심사 비용…`을 화면에서 `소마왕성` / `Lesser Demon Castle` / `小魔王城`으로 표시한다. 다른 Stage 01~04·단계 ID·중국어 단계 표기도 기존 성 이름으로 표시하고, 확인된 내부 결과 태그 51개는 화면 복사본에서 숨긴다. 원본 데이터/번역 키·API·스토리/저장 ID·실적 판정은 보존한다. 경로·사용자 지정 이름을 보호하고 중복 성 이름을 제거한다. 기존 `ui_text("Stage 04") == "第04阶段"` 계약은 유지한다.
6. 첫날 전·후열을 합친 큰 강조 상자를 각 방 바닥 안쪽 강조로 분리했다. 바깥 빛 효과까지 상단 이름표 아래에 둔다. 배치 대상·단계 13개·필수 행동·입력 판정은 유지한다.

### B. M4 꾸미기

- 기존 건설 도구의 꾸미기 버튼 또는 성 등급 표시에서 6종 팔레트를 연다: 횃불·마왕 깃발·해골 더미·자수정·수호 동상·용암 화로. 기존 화로 PNG와 절차적 도형을 사용한다. ko/en/zh_CN 카드명·설명·위압감·조작·취소/제거를 제공한다.
- 모든 장식은 1×1이다. 열린 빈 부지에 클릭/네이티브 터치로 즉시 배치하며 미리보기는 가능/불가 색을 구분한다. 방·문/길·부지 밖·장식 중복을 거부한다. ESC·취소·다른 도구 선택은 지출/변경 없이 종료한다. 제거와 기존 한 번 되돌리기를 연결하고 터치가 만든 중복 마우스 이벤트를 억제한다. 다른 손가락이 장식 입력을 가로채지 않도록 한다.
- `plot_state.layout_source.decorations[]`에 장식 종류 ID와 정수 칸 좌표를 저장한다. v6 형식은 유지하며 기존 저장의 필드 부재는 빈 장식으로 취급한다. v6 쓰기·Continue 재생성·원본 해금 이력 복원을 실제 경로로 확인했다. 잘못된 종류/좌표·중복·길/건물 겹침은 검증에서 거절한다. 새 장식 수는 최대 256개다.
- 승급의 (+6,+6) 좌표 이동을 장식에도 적용하고 그래프에서 저장 source로 다시 반영한다. 이후 저장/불러오기에서 옛 좌표로 돌아가지 않는다. 건물 이동으로 새 길/건물이 장식을 덮는 후보는 거절한다. 필수 승급의 새 방/길이 장식을 덮으면 전투 길·방은 그대로 두고 해당 장식만 가까운 빈칸으로 이동한다. 유효한 장식 자리를 먼저 예약하고 모든 ID·개수·점수를 보존한다.
- 위압감은 각 장식 1/2/1/2/3/2점을 합산한다. **기존 코드에는 연속 성 등급 점수 계산이 없어**, 기존 4단계 성장과 F~S 이름을 이용한 화면 평가를 추가했다. 성장 기본값 0/20/40/60 + 꾸밈 최대 10, 10점마다 한 등급이다. 장식 기여는 최대 한 등급이며 원시 위압감은 별도로 표시한다. 툴팁에 계산과 효과 없음·기존 부지 승급 조건 유지를 명시한다.
- 이 평가는 표시 전용이다. `graph.castle_grade`·active_rect·실제 진화 플래그/비용·부지/방 수·HP·정원·공격/방어·시설 배율·자원·적 일정·보상에는 쓰지 않는다. 장식 비용은 0이며 게임 경제 수치를 추가/차감하지 않는다.

M4는 세 언어 × 마우스/네이티브 터치로 실제 팔레트와 부지에 입력한다. 각 언어의 실제 v6 파일 쓰기·Continue, 제거/되돌리기, 승급 후 좌표·중앙 정렬과 전투 입력 불변을 검사했다. 시각 비교용 DAY15/승급/튜토리얼은 관련 상태를 설정한 재현 fixture이며 자연 캠페인 완주로 확대하지 않는다.

초기 검사에서 발견한 테스트 fixture의 빈 플레이어명/seed, 타입 추론, v6 승급 장식 좌표 보존을 교정했다. 마지막 영어 Amethyst의 한 글자 줄바꿈은 카드 안쪽 폭을 104→114로 늘리고 아이콘을 8px 옮겨 수정했으며 실제 글자 폭 검사와 3언어×2입력 GUI를 재실행했다. 새 테스트 기대값을 낮춰 통과시키지 않았다. 초기 실패 로그는 tmp에 보존한다. S1Followup 기존 `can_process` 엔진 진단 7건, GUI 기존 virtual keyboard 미지원 경고, 저장 실패를 의도한 U5-F WARNING은 구분한다. 읽기 전용 보조 1명은 화면 문구 경로와 장식 연결 코드 조사만 했으며 파일 수정·Godot·검수 판정을 맡지 않았다.

선행 의회 전환 뒤 구 개인 저장이 거절되는 문제도 복원했다. v1~v5 이관과 상층 필드가 남은 구 v6의 현재/복원용 스냅샷에서 폐기된 상층 지표 4개만 제거하고 새 1층 지표 4개를 정의의 기본값으로 채운다. 과거 실적을 신규 조건으로 환산하지 않으며, 기존 값·자료형·다른 필수 지표의 검증을 유지한다. 현대 v6의 누락 지표는 계속 거절한다. 원본 입력/파일·정확한 plot 좌표를 보존한다.
