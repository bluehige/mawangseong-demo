- 완료 조건: 실제 출전 명단과 지도/클릭 위치 일치, 편성 바로가기와 원래 화면 복귀, 예비 위치·비용 보존, 큰 초상·정확한 지원 사유, 키보드 접근, 기존 배치·Undo와 건설 안전 검사.
- 제외: 전체 캠페인·8인·사람 사용성, 미술 전체 완성, 새 버전·공개 배포·태그.

## 3. 완료한 작업

- 관리 지도에 예비 동료가 표시되던 문제를 수정했다. 렌더 대상·순서·클릭 위치를 기존 _defense_monster_ids()와 일치시켰다. 예비의 지도 드래그/클릭 배치 시작도 차단한다.
- 수비대 도구함에 출전·예비·지원 인원과 출전·예비 편성 버튼을 배치했다. 지원 전용과 미완료 외형을 예비 인원에 섞어 표시하지 않는다.
- 지도·카드·성장 목록에 기존 개체 데이터의 이름을 쓴다. 곱은 monster_instances.json의 권위 표기다. 기존 진화 이름·전투 로그·수치 계산은 유지한다.
- 편성 화면의 작은 전투 프레임 확대를 현재 형태의 큰 초상으로 연결하고, 저장된 방·현재 출전 여부를 가까이 배치했다. 지원 전용 로로의 사유를 미술 준비 중으로 잘못 설명하지 않는다.
- 미영입 후보는 성장 자료를 조회/생성하지 않고 자기 기본 초상을 표시한다. 후보 5종의 실제 화면과 미보유 상태 보존을 확인했다.
- 관리/성장에서 편성을 열면 편성 완료 뒤 해당 화면으로 돌아온다. 초기 회차 설정에서 연 경우는 기존 다음 설정 순서를 유지한다. 복귀 화면 값은 UI 메모리 상태이며 세이브 필드를 추가하지 않았다.
- 성장 화면에서 예비도 선택할 수 있다. 출전 여부와 저장 위치를 분리하고, 긴 목록에서 선택한 동료가 스크롤 안에 남도록 포커스를 복구한다. 720p·글자 115%의 잘림을 수정했다.
- 기존 예비의 room/slot과 방 정원 계산을 보존하고, 예비의 저장 자리도 정원에 포함된다는 설명을 제공한다. 선택만으로 저장 배치·자원·성장 자료를 바꾸지 않는다.
- 스토리·데이터·밸런스·AI·비용·해금·보상·저장 구조: 변경 없음. 기존 빈 deployed 목록의 모두 출전 의미도 보존했다.
