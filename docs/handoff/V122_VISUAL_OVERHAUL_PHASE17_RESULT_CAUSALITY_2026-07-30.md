## 5. 다음 설계 갈림길

재미 재검수 최소 조건은 `DAY 1에서 두 선택 중 하나를 직접 고름 → 전투에서 차이를 봄 → 결산에서 인과를 확인함`이다.

현재 튜토리얼은 푸딩을 입구에 이미 둔 상태에서 `TUT_040_DEPLOY_SLIME`을 자동 완료하므로 실제 배치 선택이 없다. 결산 인과 표시는 준비됐지만, 두 선택의 정확한 내용은 제품 설계 결정이 필요하다.

추천안은 다음과 같다.

- 푸딩은 전열, 핀은 후열에 두고 기본 역할을 먼저 학습시킨다.
- 플레이어가 곱을 직접 드래그해 둘 중 하나를 고른다.
  - `전방 봉쇄`: 곱을 푸딩과 같은 전열에 배치해 첫 교전을 강화한다.
  - `후방 화력`: 곱을 핀과 같은 후열에 배치해 뒤쪽 집중 화력을 만든다.
- 전역 지침 `사수`는 고정한다.
- 별도 능력치 보너스를 발명하지 않고 기존 배치·경로·전투 규칙으로 차이를 만든다.
- 결산은 이번 단계에서 만든 실제 기여도 문구로 선택 결과를 설명한다.

이 선택이 확정되기 전에는 DAY 1 튜토리얼 흐름을 임의로 바꾸지 않는다.
