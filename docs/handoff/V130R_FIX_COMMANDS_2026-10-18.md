## 3. 구현

`ApprovedBattleController`는 시작/교체/6초 만료/종료에서 `reset_command()`를 호출한다. 만료는 전투 시계 증가 직후 공격·AI보다 먼저 처리한다. 일점사 이동·공격·지역 대상 선택에도 유효시간을 확인한다. 잘못된 일점사 대상은 기존 명령을 취소하지 않고 거부한다.

공통 명령 수명은 기존 6초다. 일점사는 기존 사수 대비 받는 피해가 2.3배가 되는 비용을 제거했다. 기본 전역 총공격 상수는 수정하지 않았다. 명령 중 저체력 사수 방어 반응도 보존한다. 일점사 동안 AI의 안전 판단은 사수 기준을 사용하며, 실제 공격 시 총공격 배율과 지정 대상 우선을 적용한다. 이 처리는 명령 효과 수정이며 0119 기본 스탯 변경이 아니다.

캠페인 캡처에서 새 지도 컨트롤러의 일시 지침은 `defense`로 저장한다. 복원은 과거 지침 값과 관계없이 `defense`로 정규화한다. 저장 스키마·버전은 변경하지 않았다. UI는 기존 명령 아이콘 아래 초 단위 카운터를 보여주며 만료 후 숫자와 강조를 지운다. 신규 그림·음원·외부 생성 0건, 별도 미술 보류 항목 없음.
