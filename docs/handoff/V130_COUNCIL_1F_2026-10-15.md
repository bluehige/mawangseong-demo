## 3. 완료한 작업

### 맵·시설·진행

- 의회가 M6 맵을 우회하던 분기를 제거했다. 실제 자동 폭 2 길과 자유 배치 원본을 사용한다.
- `expansion_modules.json`에 왕관실·금고·보조 시설 역할을 이관했다. 계단 모듈/배치 3종은 삭제했다. `crown_sanctum`, `seal_vault`, `upper_facility_slot` 등의 내부 ID는 유지한다.
- 보조 목표 방은 3×3의 기존 바닥/문 연결 형식으로 구성한다. 이는 새 목표의 공간 연결 형식이며 HP·정원 제한·전투/시설 배율 변경이 아니다. 부지 가장자리의 문은 안쪽으로 열고 폭 2 길 검증을 통과시킨다.
- DAY16은 시설만 사용 개시한다. 등급 미달이면 기존 부지에 임시 배치하고 날짜를 막지 않는다. 포화 부지는 기존 회복/보물방을 임시 목표 위치로 사용해 기존 건물을 밀거나 무료 면적을 주지 않는다. 임시 목표에는 E18 확장 실적을 주지 않는다.
- 승급은 기존 날짜·자원 자격을 재사용한다. 자격을 늦게 충족하면 실제 해금 날짜를 저장한다. 기존 30×20 → 36×20 → 42×20 → 48×20과 +6칸 규칙을 유지한다.
- 왕관실·금고가 실제 확장 부지에 자리잡으면 구역 자격을 기록한다. 이동·회전 시 실제 배치로 다시 판정한다.

### 실제 전투·E18

- 기존 적을 왕좌와 왕관실 압박으로 연결한다. 적 수·HP·ATK·위협 예산/배율·보스 등장 시간은 바꾸지 않았다.
- 왕관실 HP600/660, 파괴 시 이번 전투 왕관 기능 억제, 다음 날 복구비24를 연결했다. 금고의 실제 경고3초/전령 수거4초, 표5 우선/부족 시 인장1, 전투당 손실1회와 포포 회수 계약을 유지한다. 베스퍼 고유 수거5초는 별도 기술 계약 그대로다.
- 실키는 기존 실제 문턱/통로 거미실을 사용한다. 포포의 실제 다른 위험 방 지원은 유지한다. 베스퍼는 실제 연결 경로를 따라 기존 예고/이동0.7초를 사용하며 왕좌로 직접 순간이동하지 않는다. 계단 큐 및 층 선택 API는 제거한다.
- `ceiling_path`의 0.60은 지원 이동 후보로만 남겼으며 일반 이동속도나 새 속도 수치로 도입하지 않았다. 미사용 다층 계산을 새 이동속도로 재해석하지 않는다.
- DAY30 담당 구역은 개체의 출전 위치에서 고정한다. 같은 종이 여러 개체여도 별도로 집계하고 이후 지원 이동이나 마지막 위치에 따라 바꾸지 않는다.
- E18 이름·본문·지표를 확장 서사로 변경했다. 왕관실 잔여HP 비율80, 생존비0.25, 본성/확장 담당 생존 각1, 무력화/절도0을 유지한다. 내부 `ending_two_floors_one_throne`, E18, priority180/base_score18000, 보상 ID와 PNG는 보존했다.
- E17~E22 직접 DAY30 문맥과 저장 지표 경로 모두 유지한다. 과거 E18 기록도 현재 제목으로 읽으며 원래 기록 자체는 수정하지 않는다.

### 서사·3언어·UI

- DAY15–18·27·29 중심 일정과 연결 비트, 편지·왕관 사건·유대·역할·스킬 설명을 ko/en/zh_CN으로 이관했다. 의회 연결 대사는 기존 대화 UI에 연결하고 본편의 별개 대화를 의회 원문으로 사용하지 않는다. DAY5는 기존 편지, DAY23은 선택한 왕관 사건을 사용한다.
- 상층 배치 선택 화면과 층 전환 HUD/키를 삭제했다. 1층 목표 안내·실제 HP·관리에서 이동/회전하는 행동과 목표 상태 표시로 대체했다.
- 숨은 층 요약/음량은 목표 경보 요약/음량으로 이전한다. 층 키는 제거하고 고대비·지역 움직임·빠른 대화 설정을 보존한다. 경보 음원은 기존 것을 사용하며 중복/소유 음원 정리를 검증했다.
- 기존 의회 선택 화면의 지연 포커스가 화면 제거 후 실행되던 엔진 오류를 `is_inside_tree`/삭제 예정 검사로 막았다. 선택/수치/진행 계약은 바꾸지 않았다.

### 저장 호환

- M6 v6 원본 좌표·회전·해금 날짜를 보존한다. 기존 v6 의회 상태 전환 전에 `.council_original` 원본을 보관한다. 구 v5 이관은 원래 파일을 덮어쓰지 않는다.
- 왕관실 HP0/억제 상태·이미 적용된 손실을 이관한다. 층 위치·전이 큐·레이아웃 잠금·자동 카메라를 폐기한다. 과거 층별 기여/생존은 새 구역 실적으로 환산하지 않는다.
- 구 회차의 방어 이력이 새 1층 실적임을 증명할 수 없으면 `record_complete=false`로 E18 새 실적을 차단한다. 다음 새 회차는 완전한 새 기록을 시작한다.
- 실제 DAY18 저장→Continue에서 전체 배치 원본/해금 이력, 목표, 진행일, E18·외형 보상 ID를 왕복 검증했다. JSON 숫자 int/float 표현은 양쪽을 동일하게 정규화한 전체 구조 비교로 검사한다.
