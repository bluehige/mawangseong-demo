```powershell
git rev-parse --show-toplevel
git branch --show-current
git rev-parse HEAD
git rev-parse main
git rev-parse origin/main
git show main:AGENTS.md
git show main:docs/handoff/CURRENT.md
```

- `main`과 `origin/main`이 다르거나 원격 최신성을 확인하지 못했으면 현재 권위를 확정하지 말고 보고한다.
