기본 전투 줌·자동/수동 관전 카메라·벽 뒤 실루엣·U5-C 구조의 슬림 HUD·클릭/터치 미니맵을 구현한다. 1920/1280에서 몸체 높이 64px 이상, 고정 HUD 높이 12% 이하, 마우스/터치 및 기존 표적 검사 PASS를 확인한다. M6 길이별 측정은 방법만 고쳐 다시 기록한다.

## 3. 완료한 작업

- 관전 기능은 별도 `SpectatorCameraDirector` 노드에 둔다. 1920의 기본 줌 1.35, 1280의 2.025로 실제 몸체의 물리 픽셀 크기를 유지한다. 수동 휠 확대 한도를 5.5로 열고, 창 크기 전환 때 사용자 줌의 상대 배율을 유지한다. 아주 작은 임시 창에서도 기본 줌 계산과 같은 최소 배율을 적용해 복귀 시 축소가 누적되지 않도록 했다.
- 현재 HP 감소, 공격/스킬 연출, 왕좌 근접 위협을 표시용 점수로 읽어 가장 관심이 높은 살아 있는 유닛 쪽으로 부드럽게 이동한다. 유닛 클릭/터치는 선택과 추적을 연결한다. 드래그/휠/미니맵은 수동으로 전환하며, 자동 설정이 켜져 있으면 5초 무조작 뒤 복귀한다. 자동/수동 버튼과 전투 설정의 켜기/끄기·적용/복원·로컬 저장을 연결했다. AI·경로·공격/피해·배속·게임 상태는 카메라에서 변경하지 않는다.
- 마우스/네이티브 터치의 포인터 소유권, 다른 손가락, 취소와 GUI 경계, 터치가 만든 중복 마우스 입력을 처리한다. 자동/수동 버튼은 네이티브 터치 release에 한 번 실행하며 뒤따르는 에뮬레이션은 차단한다.
- 새 부지 맵의 실제 닫힌 벽 PNG 알파·높이와 낮은 벽 축소를 한 번 그린 깊이 캐시에 담는다. 기존 배우 셰이더가 벽 뒤 픽셀만 아군 청록/적 붉은 실루엣으로 표시한다. 보이는 몸체는 원래 그림을 유지한다. 캐시는 배치 변경 때만 재생성하며 최대 한 변 2048px이다. 기존 미로 깊이 판정도 같은 실루엣 옵션을 사용한다.
- U5-C 정책 칩 2개·정사각형 즉시 행동/CP·특수 행동·배속/일시정지·상단 자원/메뉴·선택 유닛/대표 기술·전술/기록 패널의 기능과 잠금/거절 피드백을 유지한다. 상단 40px, 하단 88px로 축소했다. 행동 글꼴은 기존 최소 18px를 유지하고 긴 이름은 말줄임·전체 툴팁으로 제공한다. 펼친 유닛 상세는 기존 큰 초상과 기술 버튼을 유지한다. 터치 배속 행은 22px로 조정하여 일시정지를 포함한 5개 버튼을 패널 안에 둔다.
- 오른쪽 아래 미니맵은 실제 방/길 셀을 회색/금색 면으로, 살아 있는 아군/적을 청록/붉은 점으로 표시한다. 현재 카메라 범위를 테두리로 보여 주며 클릭/터치를 실제 월드 좌표로 역변환해 이동한다. 부지 밖 클릭은 기존 지도 경계로 제한한다.
- 관련 GUI 검사에서 발견한 두 결함도 수정했다. 좁은 UI 채움의 모서리 교차는 작은 사각형으로 처리한다. 건설 드래그 중 빈 땅 위의 큰 이름표에 걸려 기존 위치로 붙던 문제는 실제 방 바닥 판정으로 수정했다. 클릭 이름표 선택, 기존 방 교체·비용·되돌리기·도로 규칙은 유지한다.
- 스토리/게임 데이터/밸런스/원본 그래픽 바이트 변경 0. 기준 SHA 대비 JSON 130개가 동일하며 지정 기존 표적 검사 19파일의 기대값 변경도 0이다. 측정 도구만 관측·비교전 시험을 강화했다.

### 1920·1280 실제 캡처 측정

몸체는 현재 투명 프레임의 실제 알파 영역을 sprite/canvas/stretch 변환으로 물리 픽셀에 투영한다. 이름·HP·효과를 높이에 넣지 않는다. HUD 높이는 **상·하단 고정 띠 높이의 합**이며 미니맵·모드 버튼·선택해서 펼치는 상세는 별도로 표시한다.

| 입력/해상도 | 몸체 최솟값~최댓값 | 상단 | 하단 | HUD 합 | 화면 비율 | 판정 |
|---|---:|---:|---:|---:|---:|---|
| mouse 1920×1080 | 87.05~112.62px | 40px | 88px | 128px | 11.85% | PASS |
| mouse 1280×720 | 87.05~112.62px | 26.67px | 58.67px | 85.33px | 11.85% | PASS |
| touch 1920×1080 | 87.05~112.62px | 40px | 88px | 128px | 11.85% | PASS |
| touch 1280×720 | 87.05~112.62px | 26.67px | 58.67px | 85.33px | 11.85% | PASS |

최소 imp, slime 87.64px, goblin 112.62px, explorer 94.04/103.68px. 각 캡처에 5개 몸체를 확인했다. 미니맵은 1920에서 300×156px, 1280에서 200×104px다. 세부 좌표와 측정은 GUI 로그에서 추출한 `metrics_mouse_gui.json`(52건), `metrics_touch.json`(최종 GUI 62건)에 있다. 직접 검사 57건은 `metrics_mouse.json`과 로그에 남는다.
