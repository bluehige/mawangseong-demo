## 4. 프로젝트 계약

- 현재 제품 목표는 `진행 단순성`, `건물·몬스터 배치 재미`, `전투 밸런스`다.
- UI는 이 세 가설을 자동으로 PASS 처리하지 않고, 플레이어가 판단·행동·결과 인과를 이해하도록 지원한다.
- 현재 흐름은 `침입 확인 → 배치 → 방어 시작 → 전투 → 결과`다.
- 배치 화면은 중앙 고정 지도, 실제 침입 경로, 시설·몬스터 카드, 유효·비유효 대상, 상태, Undo와 시작 가능 여부를 연결한다.
- 전투 화면은 전장을 우선하고 목표·왕좌 HP, 4단계 방어선, 조건부 위협, 명령 대상·비용·성공·실패를 표시한다.
- 결과 화면은 승패 원인, 잘한 점, 다음 변경점, 핵심 지표와 패배 후 배치 수정을 우선한다.
