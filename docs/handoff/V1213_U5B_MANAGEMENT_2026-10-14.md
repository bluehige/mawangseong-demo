## 3. 완료한 작업

- 실제 ManagementSceneController → ManagementWorkspaceUI.build 경로를 Style B 키트 표면·버튼·폰트·아이콘과 Container 조립으로 교체했다. 상단 밀집 자원 바, 중앙 건설/수비대/전술/몬스터/전투 시작 독, 좌측 되돌리기, 우측 접이식 상세다.
- 기본은 도구 접힘이다. 독의 앞 세 항목으로 작업 띠를 펼치고 같은 항목을 다시 누르면 접는다. 튜토리얼·선택 중에는 필요한 카드가 자동으로 열린다. 지도 전체/확대/축소/휠/중간 버튼 이동을 보존하고 도구 펼침에 따라 fit 영역을 계산한다.
- 카드 이름·실제 비용 아이콘/수치, 열린 건설 구역 중 설치 수, 수비대 보유/예비/지원 상태를 표시한다. 실제 방어 구역 기준 정원/인원은 기존 함수를 사용한다.
- 건설 포인터/방향키 미리보기에 비용·효과·실제 적용 경로·고유 시설의 이전 위치 비움/재배치/강화 초기화 경고를 표시한다. 유효 위치 클릭/드롭/Enter는 기존 _confirm_build_preview로 한 번 확정한다. 카드 선택·이동·무효 위치는 지출하지 않는다. 기존 중복 확정 방어와 되돌리기 수명을 유지한다.
- 선택 방의 효과·정원·고정 구역 사유·강화 레벨/HP/시설 정원 전후·비용/불가 사유를 같은 상세에 둔다. 방 지침은 짧은 이름의 직접 선택 버튼이며 긴 설명은 별도 줄이다. 긴 상세는 스크롤한다.
- 전역 정책은 직접 선택, 현재 예상 경로 선택과 기존 문맥 행동은 스크롤 가능한 전술 작업 면이다. 확장된 행동은 HFlowContainer로 줄을 바꾼다. 기존 선택형 관리 대화/기록 진입도 유지했다. 경로 선택기의 표시 이름은 실제 경로 필드로 언어별 조립해 깨진 동적 번역을 피했다.
- 자동 관리 진입에는 오늘 예고를 통합했다. 적 칩으로 전체 읽기 전용 예고를 열 수 있으며 기존 화면 ID/스냅샷/복귀를 유지한다. 실제 새 게임→DAY1 관리 진입은 U5-A 검사에서 7입력이다. 첫 DAY 전체 루프 클릭 목표 달성이라는 뜻은 아니다.
- 출진 3초는 지도 위 하단 띠로 표시한다. 기존 준비 검사/직전 대화/스냅샷/취소/진입을 유지했다. ESC가 앞선 공통 메뉴 분기에 잡히던 경로를 출진 취소 함수에 연결했다. 배치 잠금·메뉴 시간 정지·취소 후 스냅샷 폐기를 검사했다.
- 수비대 카드의 입력 시작 좌표를 이벤트 좌표에서 얻어 짧은 클릭/드래그를 구분한다. 취소 후 살아 있는 같은 대상 또는 독 버튼으로 키보드 초점을 복원한다. 지도 이름표의 화면 경계·가림 회피와 건설 문구 클릭 판정은 같은 배치를 사용한다.
- U5-A처럼 KitButton은 인스턴스 생성 때 load한다. 다른 Workspace 하위 클래스가 쓰는 기존 panel/copy/button은 보존해 관리 전용 새 helper가 다른 화면에 전파되지 않게 했다.

### 가시 면적 정의

실제 보이는 HUD 패널과 모든 버튼의 사각형을 뷰포트/스크롤 경계로 자른 뒤 합집합 면적을 구한다. 화면 전체에서 그 실제 가림을 뺀 값이다. 뒤에 지도가 렌더된 패널 면적은 세지 않는다. 지도 안 이름표는 지도 표시로 구분한다. 지도 타일 자체가 화면을 채운 픽셀 비율 또는 새로운 지도 구조의 크기 측정은 아니다.
