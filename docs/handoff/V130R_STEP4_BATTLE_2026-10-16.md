## 3. 구현 사항 — 사용자 확인 대기

- 0089 미리보기의 전투 탭 활성화. 빈 수비대는 시작 거절, 실제 배치 개체만 소환. 전투 중 건설/배치로 변경하지 못한다. 생산 명단 고유14명·기존 능력치/스킬 데이터 유지.
- `ApprovedBattleController`는 `CombatSceneController`를 상속한다. 일반 공격·피해 계산·위협/표적 규칙·자동 스킬 조건·기존 스킬 준비/효과/비용/쿨다운·기여/보상·승패 결과 서비스를 호출한다. 지도용 이동, 영향범위와 전장 내 시전 표현만 치환한다. 원본 `CombatSceneController.gd`, `Unit.gd`, `waves.json`, `enemies.json` 수정0.
- `ApprovedBattleUnit`는 기존 `Unit.gd`를 상속해 상태·실제 이동·프레임 애니메이션·피해·회복을 재사용한다. 시뮬레이션 좌표는 화면 카메라와 분리하고, 같은 살아 있는 sprite/이름/HP 그림만 지도 변환 아래에 표시한다. 그림자/선택/HP는 GPT 텍스처 조립, 글꼴은 NEXON_Maplestory Bold/Light.
- 길 칸과 다리만 A* 통과. 대각선 금지, 경로 캐시, 목적 칸이 그대로면 매 AI 갱신마다 경로를 되감지 않는다. 실제 입구 문 앞 두 칸에서 `waves.json` 해당 DAY 시간표·능력치 배율로 적을 생성한다. 근거: [Godot AStarGrid2D 공식 문서](https://docs.godotengine.org/en/stable/classes/class_astargrid2d.html).
- 기본 적→옥좌, 도둑→미끼 보물실(있으면5초 지연)→금고, 없으면 바로 금고. 금고는 기존5초 약탈·최대100금화 차감·입구 탈출 규칙. 시설 목표는 가장 가까운 실제 건물, 해당 지도에 없는 심장 목표는 옥좌로 매핑한다.
- 기존 몬스터 AI에 수비 칸 기준 국소 적 목록을 전달한다. 기본 목줄은 길3칸 상당 월드 거리약214.66px. 사거리 안 교전, 범위를 벗어나면 실제 자기 칸으로 복귀. 명시 이동 명령6초/직접 조종은 예외이고 종료하면 정상 목줄로 돌아온다.
- 전술 집결/집중/비상 후퇴/사수/후퇴 유도는 그림+툴팁으로 조작. 집중은 선택 적을 실제 공격 표적으로 우선하며, 사수 중 추격하지 않고, 후퇴 이동을 일반 공격이 취소하지 못하게 했다. 집결/유도는 길 클릭, 집중은 적 클릭. 기존 전술 배율을 재사용하고 새 비용은 도입하지 않았다.
- 하단 속도 정지/1/2/3 그림, Space 정지. 정지는 유닛 상태/이동과 전투 Tween을 멈춘다. 몬스터 클릭 시 바로 옆 실제 스킬 아이콘과 신규 `skill_direct_control_v2`; 직접 조종 중 우클릭 길 이동, 재클릭 자동 복귀. 스킬 창 아래 길에도 우클릭 이동 가능.
- 옥좌0 패배, 남은 시간표가 끝나고 살아 있는 적이 없으면 승리. 기존 결과 화면의 전투 기여/EXP/보상/다음 진행 액션을 재사용하되 글씨 버튼을 그림으로 바꾸고 기존 절차형 surface는 숨겨 GPT 패널로 표시한다. 결과 화면은 고정 구조가 유지돼 얇은 행의 금색 테두리가 조밀하다. 화면 취향은 사용자 확인 대기.
- 사용자 저장 플래그4개를 끄고 APPDATA/LOCALAPPDATA를 ignored tmp로 격리한다. 앞 단계 시험 JSON은 읽기만 하며, 전투와 정산은 이 실행의 메모리에서만 진행한다.

### 신규 몬스터용 API 계약

| 진입점 | 반환/효과 |
|---|---|
| `unit.get_cell_tags()` | 현재 칸 Dictionary |
| `unit.get_cell_tags(target_unit)` | 대상 현재 칸 Dictionary |
| `battle.map.tags_at(Vector2i)` | 특정 칸 Dictionary |
| 태그 필드 | `cell:Vector2i`, `road/bridge/water_adjacent:bool`, `trap:""/"spikes"/"sticky"`, `defense_line:"1"/"2"/"final"`, `aura:Array[String]`(건물 인스턴스ID) |
| `unit.create_temporary_trap(cell,kind,seconds,source_id)` / `battle.create_temporary_trap(...)` | 길/종류/양수 시간을 검증, `ok`, `remaining`, `source_id` 등 반환. 기존 함정을 덮었어도 만료 시 원래 칸 함정 복원 |
| `battle.add_trap_duration_modifier(cells,multiplier,seconds,source_id)` | 일정 칸에 제한 시간 배율 등록 |
| `unit.trap_duration_multiplier(cell)` / `battle.trap_duration_multiplier(cell)` | 현재 유효 배율 곱. 기본1.0 |

임시 함정 수명은 생성 시 배율을 적용하고, 끈끈이 감속 지속시간도 발동 시 배율을 조회한다. 느릿은 이 계약을 호출하면 되며 느릿 자체의 합류/그림/명단 통합은 이번 범위가 아니다. 태그는 몬스터/적 양쪽 유닛에서 제공한다.
