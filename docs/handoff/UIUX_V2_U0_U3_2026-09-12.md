## 3. 완료한 작업

### 실제 흐름

이전: 빈 슬롯 → 작은 문맥 시설 목록 → 윤곽 미리보기 → 먼 상세창 확정. 상시 로스터와 여러 관리 행동이 동시에 노출됐다.

변경 후: 하단 건설 도구함의 실제 시설 모습 → 끌어서 기존 구역에 맞추기 → 드롭으로 후보 선택 → 하단 검토 바에서 비용·효과·고유 시설 이동·수비대 재배치·환급 없음 확인 → 명시적 확정/취소 → 기존 1회 Undo.

카드 클릭 후 맵 클릭, 키보드 포커스·Enter/Space·방향키도 같은 검토·확정 경로를 사용한다. 빈 슬롯 클릭과 기존 문맥 상세의 건설 버튼은 같은 도구함의 단축 진입이다. 현재 관리 씬의 건설 처리 경로는 하나다. 실행되지 않는 legacy UI 함수는 이력 호환용으로 일부 남아 있다.

관리 화면은 상단 상태/침입 안내, 지도, 하단 건설·수비대·전술 탭, 선택할 때만 열리는 상세, 분명한 방어 시작 버튼으로 조립한다. 수비대는 실제 초상화·이름·현재 방을 먼저 표시한다. 기존 연결로·원정·연대기·후반 행동은 전술 탭의 실제 콜백을 유지한다. 필수 결정과 튜토리얼 진행 안내를 유지했다.

### 활성 호출 추적

- 입력: FacilityCard.gui_input → BuildingPlacementController.begin/update_pointer/drop → select_candidate.
- 클릭 대안: _set_build_facility → _handle_left_click → _select_build_target_room → 같은 select_candidate.
- 확정: _confirm_build_preview → _evaluate_facility_placement → 기존 _change_room_facility → 기존 GameState.pay / _apply_facility_to_room / 수비대 재배치 / 맵 갱신.
- Undo: 기존 _capture_management_undo / _undo_last_management_placement.
- 실제 외형: ModuleGraph.facility_preview_slots → QuarterDungeonRenderer.facility_visual / draw_facility_visual → 실제 맵과 같은 floor footprint, object texture resolver, stage/facing, 바닥 기준점.
- 화면 조립: GameRoot._set_screen(management) → ManagementSceneController.build_management_ui → ManagementWorkspaceUI.build.
- 기존 전투 명령: CombatSceneController / V122CommandService 유지. 새 전투 확인창 없음.

미리보기는 표현 전용 Control이다. 방 인스턴스·몬스터·자원·경로·튜토리얼 상태를 만들거나 변경하지 않는다. 자원과 해금은 확정 시 다시 평가한다. 고유 시설은 원래 규칙대로 이전 위치가 빈 슬롯이 되는 이동이며 이를 검토 바에 경고한다. 전체 자유 타일 건설이나 새 경로/저장 시스템을 추가하지 않았다.

UI 위 드롭, 지도 밖, 고정 방, ESC, 포커스 상실, 탭/화면 전환과 중복 확정 입력을 처리한다. 입력 좌표는 캔버스 역변환을 거쳐 정확한 타일 소속으로 판정한다. 기존 nearest-room 보정으로 지도 밖을 유효 방으로 오인하지 않는다. 고스트는 앞벽보다 앞에서 렌더한다.

썸네일 구성은 시설/성 단계/방향을 포함한 캐시를 공유한다. 마우스 이동 때 HUD 전체를 새로 만들지 않는다. 확정 때 기존 ui.confirm 음원과 0.32초 테두리 반응을 재생한다.

수비대의 키보드 선택 후 맵 몬스터 클릭이 새 드래그로 덮이는 문제와 취소 후 로스터 출발 플래그가 남는 문제도 직접 테스트로 수정했다.

### 보존 범위

제품 데이터·비용·성장·AI·스토리·보상·세이브 형식·제품 버전·기존 시설 구역을 변경하지 않았다. 미확정 건설에서 자동 저장 예약을 막고, 기존 선택 관찰 기록은 실제 건설 성공 시점으로 옮겼다. Undo는 마지막 시설/수비대/연결로와 관련 자원을 복구한다. 성장·전투·관찰 기록까지 되돌린다고 표시하지 않는다.
