## 3. 완료한 작업

- **설정 단일 편집기:** 화면 / 소리 / 조작·접근성 / 대화·안내 / 전투 연출의 5탭. U5-D/E의 기존 왕좌 배경, B 테마, 반투명 패널·카드, 기존 핀 그림을 재사용한다. 드롭다운/슬라이더/기존 행동에도 B 스타일을 적용했다. 적용/취소는 본문 스크롤 밖에 고정한다.
- **접근성 이전:** 연대기의 편집 컨트롤·즉시 저장 신호를 제거하고 같은 설정 화면의 접근성 탭 바로가기만 둔다. 빠른 대사는 대화·안내, 층 경보 음량은 소리, 배속 기억은 전투 연출에 위치한다. 기존 층 키·고대비·숨은 층 요약·지역 정보·지도 움직임 키와 정규화는 유지한다. 상층/2층 화면 파일과 동작은 수정하지 않았다.
- **저장:** 일반 설정은 기존 `user://settings.cfg`의 같은 섹션/키, 접근성은 기존 캠페인 프로필의 `chronicle_update4.accessibility`를 사용한다. 접근성은 draft만 수정하고 적용 때 저장한다. 일반 설정의 4개 writer에서 기존 오류를 bool로 반환하도록 연결했다. 실패하면 이전 파일 내용을 복구하고 편집기·오류·재적용/취소를 유지한다. 취소는 음량/화면/언어/안내 이력/입력 미리보기를 복원한다.
- **타이틀 저장 경계:** 저장이 있으면 기존 v5 writer로 저장된 프로필의 접근성만 갱신하고 active_run·다른 프로필·연대기 기록/이벤트 ID를 보존한다. 초기 타이틀의 빈 실행 상태로 캠페인을 덮어쓰지 않는다. 캠페인 저장이 없는 첫 실행은 기존 연대기 진입 조건을 유지해 캠페인 접근성만 비활성화하고 “새 게임 후 조절”을 표시한다. 일반 설정은 바로 적용할 수 있다. 새 게임/이어하기를 임의로 만들지 않는다.
- **기록실:** 연대기와 엔딩 도감을 같은 배경·탭·목록/본문·복귀 문법으로 연결한다. 해금된 엔딩만 목록/이름/그림/본문을 만들며, 미해금 서신·후일담의 제목/본문/힌트도 만들지 않는다. 카탈로그가 원래 허용하는 전선·심장·동료의 조건은 유지한다.
- **동료 연결:** 기록실의 동료 선택 → A04 기억/도감, 돌아가기 → 같은 연대기 탭·분야·스크롤 위치. 기록실을 벗어나면 복귀 컨텍스트를 지워 이후 일반 몬스터 화면의 Back은 관리로 돌아간다. 기록/대화 로그를 다시 읽어도 날짜·자원·동료/프로필·이벤트 기록이 바뀌지 않는다.
- **게임 메뉴:** 계속/저장/불러오기/설정/타이틀/종료의 기존 콜백과 확인 절차를 유지하며, 작은 무라벨 아이콘을 B 스타일의 이름 있는 2×3 버튼으로 교체했다. 설정 취소는 원래 일시정지 메뉴로 복귀한다.
- **음악:** 후보는 `data/audio/music_playlists.json`, 선택은 `MusicRotation.gd`. 카탈로그의 실제 파일 경로를 중복 제거하며 장면별 커서·전역 마지막 파일을 사용한다. 여러 곡은 무한 loop를 해제하고 곡 끝 0.65초 전에 두 플레이어로 크로스페이드한다. 현재 플레이어의 finished 신호도 후속 전환을 보완한다. 화면 재구성/전투 반복 갱신은 순환곡을 초기 곡으로 되돌리지 않는다. 기존 보스/위기/최종 상태 resolver 우선순위와 설정 진입 시 음악 유지는 보존한다.
- **전환/종료 정리:** 정지 도중 복귀는 예약된 stop을 취소한다. 현재 BGM이 있으면 설정 미리듣기를 겹치지 않는다. 종료는 먼저 플레이어/타이머/캐시를 정리하고 새 UI 효과음을 차단한 뒤 0.05초 후 수행한다. 새 보상/게임 효과·저장 형식 변경은 없다.
