- 구현: 전투 입력에서 카메라 수동 역산 대신 Godot 전역 마우스 좌표를 사용해 해상도·줌에 따른 대상 클릭 오차를 줄였다.
- 구현: 집결·후퇴의 방어 구역 표식 중심을 직접 클릭하면 방 타일 판정이 빗나가도 가장 가까운 유효 구역을 선택하도록 보완했다.

- UI/UX: 버튼의 활성·쿨다운 문구도 실시간 상태를 표시하도록 맞췄다. 기존의 버튼 → 노란 대상 클릭 2단계 사용법과 명령 비용·지속시간은 유지했다.
