## 3. 완료한 작업

- `frontend-skill` 기준으로 시각 논지·콘텐츠 계획·상호작용 논지를 먼저 고정했다.

- 1920:
  - 지도 전체를 상태 레일과 하단 rail 사이의 주 작업면으로 사용한다.
  - 선택 drawer 진입 시 지도를 안전 작업영역으로 재중심해 핵심 구조를 가리지 않는다.
  - Primary는 `방어 시작` 하나만 사용한다.
- 1280:
  - 지도와 캐릭터 최소 표시 크기를 단순 축소하지 않는다.
  - 설명·장식·중복 상태를 접고 drawer가 핵심 지도 영역을 가리지 않는다.
- UI:
  - Primary / Tactical / Utility·Status의 3등급을 표시했다.
  - 위험 적갈은 별도 프레임 등급이 아니라 치명 경고 의미색으로 제한했다.
  - 밝은 판단 황금은 화면당 현재 판단 지점 또는 Primary 하나만 사용한다.
- 환경·캐릭터:
  - 입구·병영·회복실·보물실·건설 슬롯은 유지, 왕좌는 교체 대상으로 표시했다.
  - 슬라임·고블린·임프·수습 용사를 같은 발 기준선과 접촉 그림자 위에 비교했다.
- 전투 합성:
  - `바닥 → 접촉 그림자 → 선택 링 → 캐릭터 → 일반 VFX → 이름·체력 → 치명 경고` 순서를 고정했다.
