- 네 칸이 만나는 꼭짓점의 점유 상태로 바깥/안쪽 모서리를 고르는 이중 격자 방식을 사용한다. 경계는 연속 구간을 찾은 뒤 GPT 연석·물길 경계 조각을 이어 붙이며, 내부 칸 사이에는 연석을 만들지 않는다. 절벽·부지 뒤 경계·외부 접근로·입구 다리는 승인 조각을 재사용한다.
- 이 진입점의 지형은 승인 등급 **E 32×18**이다. 물길은 plan의 `~B`에서 고정 지형으로 추출한다. 다른 등급의 새 확정 칸 데이터가 없어 F~S의 새 지형을 임의로 만들지 않았다.
- 주 통로는 고정 입구·옥좌·금고 소켓과 두 수로 열에서 재계산한다. 건물마다 2×2 통과 가능한 앵커를 만들고 기존 `AutoRoadBuilder.defense_search()`의 A*(비용이 적은 길 찾기)를 호출한다. 재사용6/새 칸10, 꺾임60, 벽 인접4, 꺾기 전 최소 직선 길이 규칙을 재사용한다. 승인 문 방향을 우선하고 그 소켓이 연결되지 않을 때 다른 방향을 찾는다.
- 길과 고정 물길의 교집합에는 다리 조각이 자동 생성된다. 세로 수로를 x축으로 건너는 방향과 가로 수로를 y축으로 건너는 방향을 구분하고, 후자는 승인 다리 조각을 좌우 반전해 조립한다.
- `plan_E`의 **모든 길 칸·문 방향·수비18칸이 동적 계산 결과와 동일**하다. 해당 배치의 길 셀을 캐시에서 복사하거나 승인 `draw_list`로 대체하지 않는다. 변한 건물의 문·벽·실내·문턱은 새 위치에서 만들고 발 깊이와 동일 깊이 삽입 순서로 정렬한다.
- 물길 위, 시설과 겹침, 부지 밖, 고정 시설 이동, 입구→옥좌/금고 주 통로 차단을 거절한다. 모든 문/길에 독립 연결 검사를 적용한다. 재배치 후 기존 함정 아래 길이 사라지는 배치도 거절한다.

### 건설 UI·범위

- 하단 GPT 아이콘 7개: 병영·회복 둥지·결계핵·감시탑·미끼보물실·가시·끈끈이 함정. 클릭 후 위치 클릭과 누른 채 드래그를 모두 지원한다. 다중 자원 비용은 두 줄로 표시해 인접 가격과의 겹침을 없앴다.
- 후보 원점 576개를 같은 모델로 검사한다. 입력이 멎지 않게 12개마다 프레임을 넘기며, 유효 원점은 녹색 빛, 불가는 옅은 적색이다. 포인터 아래 전체 건물 footprint는 즉시 최종 녹/적 판정으로 표시한다. 후보 표시가 한 프레임에 전부 뜨는 방식은 아니다.
- 드래그 중 반투명 실내·벽·문, 금색 문 앞 두 칸, 보라색 영향 칸, 청색 새 길 미리보기를 조립한다. 고스트 문턱이 실제 맵에 누적되는 문제도 수정·재검증했다.
- 배치하면 길·문·다리·빈 수비 지점·범위를 갱신하고 테스트 사본에 자동 저장한다. 정원만큼 서로 겹치지 않는 마른 길 칸을 수비 지점으로 배정한다. 새 지점은 금색 GPT 칸 그림이다. 1단계와 같은 건물·수비 칸의 기존 몬스터 그림만 비교용으로 유지하며 유닛을 편성하거나 전투 객체를 만들지 않는다.
- 건물 클릭 → 둘레의 정보/강화/이동/해체·환불/수비 GPT 아이콘. 정보창은 해당 건물 옆을 따라가며 화면 밖일 때만 반대편으로 옮긴다. 고정 모서리 패널 없음. 해체는 환불액을 보여 준 뒤 두 번째 이미지 확인 아이콘을 눌러야 실행한다. 강화도 옆 창에서 가격을 보여 주고 확인한다.
- 수비 아이콘은 빈 수비 지점만 표시한다. 몬스터 편성 화면과 전투는 연결하지 않았다.
- 표시 그림은 승인 GPT PNG·기존 GPT 흑요석 패널·새 GPT 투명 칸 그림이다. 코드 장식 도형이나 글씨 버튼을 추가하지 않았다. `TextureButton`에는 이미지, 별도 `Label`에는 이름·수치·짧은 상태/조작 안내만 둔다.
