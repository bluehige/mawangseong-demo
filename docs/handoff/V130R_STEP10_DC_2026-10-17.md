- **추천 우위 미충족:** DAY20/21/22/23/24/26/27은 집중 배치가 승률 또는 평균HP에서 더 강하다. 예: DAY20 추천80%/50.6%, 집중①90%/58.9%; DAY23 추천90%/50.8%, 집중①100%/71.6%. DAY25/28/30은 추천의 두 지표가 집중3종 이상이다. 결과를 숨기거나 우위만 맞추는 추가 수치 보정을 하지 않았다. 이 차이를 인정할지 별도 보정할지는 헤드 판단이다.

- 낙수 애니메이션과 닫힌 관문 상태는 추가하지 않았다. 새 UI 그림·도형/글씨 전용 버튼은 만들지 않고 기존 GPT 버튼과 아이콘을 조립했다.
- 후보54건은 `balance_experiments.json`에 요약했다. 초기27건은 중간 소스 탐색이라 최종 검수 근거가 아니다. 후속27건은 동결 런타임의 후보 웨이브 시험이며 채택 여부를 구분했다. 원자료는 각 항목의 `raw_archive` 경로를 따른다. 시간 초과 후보는 최종400회에서 제외했다.

## 9. 작업 트리·안전

기존 혼합 트리를 유지하고 명시한 파일만 스테이징했다. 기존 미커밋 파일은 그대로이고, 요청한 PNG·축소본·원자료는 로컬 미커밋 산출물이다. 개인 사용자 세이브는 읽거나 수정하지 않았다. APPDATA/LOCALAPPDATA와 테스트 저장은 `tmp/v130r_step10`에 격리했다. Godot은 동시1개를 유지했고 최종 촬영 종료 후0개를 확인했다. 원격 푸시 없음.

AGENTS.md의 소스 브랜치 로컬 캡처 금지에 따라 검수 PNG·축소본과 상세 전투 원자료는 지정된 로컬 폴더에 두고 커밋하지 않는다. 코드·게임 그래픽 원본/런타임·도면 자료·Markdown 보고서·핸드오프만 명시적으로 커밋한다. 이전 Step8B/Step9 검수 폴더도 Markdown 보고서만 추적하고 있다.
