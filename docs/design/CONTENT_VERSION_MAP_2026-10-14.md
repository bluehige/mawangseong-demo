### 최초 포함 태그의 한계

로컬 제품 태그는 `v1.2.0`~`v1.2.10`만 존재한다. 요청 범위의 `v1.0.0`·`v1.1.0`·`v1.2.11`은 **로컬 부재**다. 아래 **T**는 `v1.2.0`이 *확인 가능한 태그 중 최초 포함*이라는 뜻이며, 1.0/1.1 최초 포함 여부는 미확인이다. ‘현재 완성된 동작이 그때 이미 완성’이었다는 의미도 아니다.

`git log --reverse HEAD -- <대표 경로>`와 `git tag --contains <도입 SHA>`를 교차했다. v0.1 기반은 `3e69145`, v0.2는 `98eb6e6`, v0.3는 `1f80877`, v0.4 모드/런타임은 `66959fb`/`f1465af`에서 확인되며 모두 최초 로컬 제품 태그 `v1.2.0`에 포함된다. 도입 당시 서비스·데이터도 `git cat-file`/`git show`로 확인했다. 현재 표의 UI 경로 일부는 이후 교체본이며 T가 새 UI의 도입 태그를 뜻하지 않는다. 더 오래된 `v0.*` 태그는 감사 기록일 뿐 새 제품 번호로 바꾸지 않는다. `—`는 해당 기능 도입을 확인할 수 없다는 뜻이다.
