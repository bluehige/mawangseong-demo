# 1.2.12 수정판 공통 UI 기준

- 1920×1080 논리 좌표: 본문 기본·권장 20px 이상, 보조 설명과 자동 맞춤의 절대 하한 18px. 버튼 기본 22px, 최소 18px. 글자를 9px까지 축소하던 자동 맞춤을 금지하고 영역·줄바꿈으로 조정한다.
- 버튼 최소 높이 44px, 아이콘 버튼 48×48px, 내용 여백 좌우 12px·상하 8px. 아이콘 32px, 버튼 사이 8px 이상. 주요 시작·적용 행동은 이름을 유지한다.
- 툴팁: 이름 + 행동 설명, ko/en/zh_CN. 22px, 최대 폭 560px, 좌우 14px·상하 10px, 불투명에 가까운 어두운 바탕과 금색 테두리. 비활성 사유도 표시한다.
- 언어 선택은 자동 번역하지 않는 `한국어 / English / 简体中文` 선택지다.
- 21:9는 기본 16:9 좌표와 비율을 유지하며 좌우 여백으로 전체 화면을 보존한다. 던전 구조나 대화창의 배치는 이번에 개편하지 않는다.
- 구현 기준: `scripts/ui/UIStandard.gd`, 공통 생성기 `HUDController.gd`. 사용자 작은 글자 설정에서도 논리 좌표 하한을 유지한다.
