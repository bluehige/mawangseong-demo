## 시각 논지

2. 1280 compact 관리 화면
3. UI 프레임 3등급과 7개 팔레트 역할
4. Stage 01 방 6종과 DAY 1 전투 캐릭터 4종의 같은 크기 비교

6. 승인 뒤 적용할 상호작용과 제작 범위

## 상호작용 논지

- 선택 전에는 이동 가능한 바닥과 문턱 자체로 경로를 읽고, hover 시 대상 주변에 80ms 국소 윤곽만 나타난다.
- 방 선택 시 우측 drawer가 160ms로 들어오고 지도 카메라는 남은 안전 작업영역으로 재중심된다. 두 입구·두 전선·왕좌와 현재 대상은 drawer 뒤에 숨지 않는다.
- 1280 compact에서는 설명문과 장식이 접히고 상태·대상·주 행동만 남으며, 지도와 캐릭터의 표시 크기는 단순 축소하지 않는다.

## 화면 구조

### 1920 full-canvas

- 성 지도: 화면의 주 작업면, 상단 상태 레일과 하단 수비대·주 행동 레일 사이 전체
- 상단: 자원·DAY·왕좌 체력의 얇은 상태 레일
- 우측 drawer: 방·적·몬스터를 선택했을 때만 표시하며 열린 동안 지도는 안전 작업영역에 맞춰 재중심
- 하단: 수비대 rail과 Primary `방어 시작` 하나
- 정적 황금 장식: 사용하지 않음

### 1280 compact

- 성 지도: 1920과 같은 시각 중심과 캐릭터 최소 표시 크기 유지
- 상단: 아이콘·수치 중심의 한 줄 상태
- 우측 drawer: 폭과 본문을 줄이고 지도 안전 작업영역을 침범하지 않음
- 하단: 현재 행동과 Primary 중심, 보조 기능은 짧은 라벨
- 긴 설명·중복 상태·장식 프레임: 숨김

## UI 프레임 3등급

| 등급 | 역할 | 시각 규칙 |
|---|---|---|
| Primary | 화면당 하나의 주 행동 | 밝은 판단 황금, 가장 두꺼운 3px 상태선 |
| Tactical | 전술·대상 선택 | 마력 보라의 저채도 테두리, 선택 시 2px |
| Utility / Status | 정보·보조·취소 | 철색 또는 어두운 황동, 1px 이하 |

위험 적갈색은 네 번째 프레임 등급이 아니라 삭제·패배·치명 경고의 의미색으로만 사용한다.

## 팔레트 역할

| 역할 | 색 | 용도 |
|---|---|---|
| 암부 | `#07060B` | 화면 끝, 암벽 void |
| 패널 | `#111019` | drawer·상태 레일 |
| 어두운 황동 | `#766044` | 정적 장식·구분 |
| 마력 보라 | `#8C6AB0` | 마력·특수 상태·전술 |
| 판단 황금 | `#F0C85B` | 현재 선택 후보 또는 Primary 하나 |
| 위험 적갈 | `#B65A59` | 위험·파괴·실패 |
| 정보 청회 | `#6F91A8` | 설명·정보·비활성 상태 |

## 환경·캐릭터 기준

- 방 6종은 같은 박스·같은 alpha 여백·같은 시각 중심으로 비교한다.
- 왕좌는 교체 대상, 나머지 5종은 유지·접합 보정 대상으로 표시한다.
- 슬라임·고블린·임프·수습 용사는 같은 발 기준선과 접촉 그림자 위에 놓는다.
- 캐릭터 공통 기준은 이소메트릭 30~35도, 좌상단 온광, 보라 환경 반사광, 채도 상한, 얇은 림라이트다.

## 전투 합성 순서

1. 바닥
2. 접촉 그림자
3. 선택 링
4. 캐릭터
5. 일반 VFX
6. 이름·체력
7. 치명 경고

- 미선택 링은 숨긴다.
- 이름·체력은 캐릭터 실루엣 바깥에서 충돌을 피한다.
- 일반 VFX는 캐릭터 면적과 최대 휘도를 넘지 않는다.

## 승인 범위

보드 승인 시 다음 네 가지를 동시에 확정한다.

1. 1920 full-canvas와 1280 compact의 작업면 비율
2. UI 프레임과 팔레트 역할
3. 환경·캐릭터의 공통 크기·광원·접지 기준
4. 전투 합성 순서와 시각 예산

승인 전에는 신규 왕좌·문턱·복도·캐릭터 보정 자산을 생성하거나 런타임에 연결하지 않는다.
