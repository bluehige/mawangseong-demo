# V1.2.2 구조용 던전 벽 V2 계약

## 해결해야 한 실제 문제

1. `connected` 소켓마다 예전 `door_open_*` 문틀과 횃불을 그려, 비어 있어야 할 2칸 통로에 최대 네 개의 장식물이 겹쳤다.
2. V1 벽과 정점은 높고 보라색인 독립 오브젝트여서 유닛·이름을 가렸고, 이어지는 벽보다 장식 탑처럼 보였다.
3. 대각선으로 점 하나만 닿은 서로 다른 외곽선을 하나의 4방향 분기점으로 합쳐, 벽과 무관한 접합물이 생겼다.

## 최종 상태 규칙

| 경계 상태 | 바닥 | 구조 벽 | 별도 장식 |
|---|---|---|---|
| `connected` | 연결 | 없음 | 없음 |
| `closed` | 차단 | 낮은 구조 벽 1개 | 없음 |
| `open_placeholder` | 차단 | 낮은 구조 벽 1개 | 없음 |

- 연결된 통로는 완전한 빈 공간이다. 문틀, 횃불, 석주, 표지 PNG를 자동 배치하지 않는다.
- 문이 실제 맵 오브젝트로 명시된 경우만 별도의 문 자산을 사용할 수 있다.
- `open_placeholder`는 아직 뚫리지 않은 벽 상태다. 구조 벽만 유지하고 예전 건설 표지 석주를 겹치지 않는다.
- 기존 `door_open_*`와 `socket_placeholder_*`는 런타임 후보가 아닌 격리 자산으로만 기록한다.

## 구조 조립 규칙

1. 공용 topology builder가 실제 격자 반쪽 변을 하나의 물리 벽으로 정규화한다.
2. 열린 변은 벽 목록에서 제외하고, 닫힌 변과 placeholder 변만 벽 사슬에 포함한다.
3. 직선은 축별 `NE_SW`, `NW_SE` segment를 사용한다.
4. 모서리, 끝, T분기는 접속 방향을 계산해 방향별 자산을 선택한다.
5. 같은 축의 두 벽이 곧게 이어지면 정점 자산을 추가하지 않는다.
6. 대각선 방 두 개가 점 하나만 공유하면 소유 셀별 가상 정점으로 분리한다. 이 경우 교차점이나 분기탑을 만들지 않는다.
7. 4방향 교차점은 자동 장식으로 덮지 않는다. 유효한 방향 자산 계약이 생기기 전까지 빈 정점으로 남긴다.
8. `N/W` 벽은 유닛 뒤, `E/S` 벽은 유닛 앞에 놓되 벽 높이를 낮춰 몸과 이름을 가로지르지 않는다.

## V2 자산 규격

- 런타임 경로: `assets/tiles/cave_v2/structural_walls_v2/`
- 캔버스: 투명 `256×256` PNG
- 벽 높이: 정확히 2단 석재
- `1280×720` 셀 경계 반복 간격: `19.5~20.5px`
- `1280×720` 한 bitmap의 겹침 포함 connector span: `22~22.5px`
- `1280×720` 벽 중심의 벽축 직각 두께: `9~10px`
- `1280×720` 벽 중심의 세로 alpha 외곽: `10~11px`
- `1280×720` 대각 위치 차이를 포함한 전체 bitmap 세로 외곽: `20~21.5px`
- 원본 `256×256` PNG의 `source_anchor_extent_px`는 최대 `138px`다. 이 값은 화면 높이가 아니라 후처리 자산의 anchor와 전역 alpha bbox 사이 거리다.
- 직선: 두 화면 축 2종
- 모서리: `WN`, `NE`, `ES`, `SW` 4종
- 끝마감: `N`, `E`, `S`, `W` 4종
- T분기: `NEW`, `NES`, `ESW`, `NSW` 4종
- 총 런타임 자산: 14종
- 금지 요소: 보라·자홍 조명, 횃불, 문틀, 깃발, 문양, 독립 기둥, 바닥판, 잔해

- 깊은 그림자: `#121416`

- 윗면: `#34383B`

## 자동 검증

- 활성 세트가 V2 14종과 방향별 슬롯을 모두 갖추지 못하면 실패한다.
- 연결 통로가 구조 벽, portal marker 또는 socket marker를 하나라도 가지면 실패한다.
- legacy 장식물이 구조 슬롯으로 돌아오면 실패한다.
- 접속점 alpha, 2:1 기울기, 원본 anchor 범위, 2단 석재, 회흑색 팔레트 조건을 검사한다.
- 실제 렌더 공식과 실제 PNG alpha로 `1280×720` 셀 경계 간격·겹침 포함 connector span·벽축 직각 중심 두께·중앙 세로 외곽·전체 bitmap 세로 외곽과 모서리·끝·T분기 폭을 각각 검사한다.
- 대각선 점 접촉이 하나의 junction/cross로 합쳐지면 실패한다.
- Stage 01~04와 구조가 다른 사용자 맵이 같은 공용 규칙을 사용하지 않으면 실패한다.
- 대표 화면은 `1280×720`에서 실제 렌더해 통로 공백, 벽 연결, 유닛·이름 가림을 확인한다.
