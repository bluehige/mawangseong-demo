# v1.2.2 관리·배치 화면 Full-canvas 레이아웃 계약

기준일: 2026-07-29
적용 대상: Windows 출시판, 데스크톱 웹 테스트판
제외 대상: 모바일 웹

## 1. 시각 목표

- 성 지도는 화면 전체에 유지한다. 방 선택이나 문맥 드로어 개폐 때문에 지도를 이동하거나 축소하지 않는다.
- 상단 상태, 수비대, 주요 행동은 지도 위에 얹는 얇은 오버레이로 처리한다.
- 금색은 현재 선택과 `방어 시작` 같은 주 행동에만 사용한다.
- 보라색은 방·전술 문맥, 붉은색은 실패·위험, 녹색은 성공 피드백에만 사용한다.
- 장식 프레임은 정보 위계를 보조하는 수준으로 제한하고 지도와 캐릭터를 가리지 않는다.

## 2. 정보 우선순위

| 단계 | 항상 노출 | 표현 |
|---|---|---|
| P0 | 자원, 날짜, 성 체력, 지도, 수비대, 방어 시작 | 상단 HUD + 지도 + 하단 얇은 레일 |
| P1 | 선택한 방의 지침·시설, 필수 결정 | 우측 문맥 드로어 |
| P2 | 배치 피드백, 시작 불가 이유 | 하단 상태 문장·툴팁 |
| P3 | 연대기·원정·전초기지·상층 왕성 | 문맥 드로어의 추가 작전 |

시설 목록과 몬스터 목록을 화면에 전부 펼치지 않는다. 몬스터는 수평 스크롤 수비대 레일에서 드래그하고, 시설 후보는 선택한 방의 문맥 드로어 안에서만 연다.

## 3. Standard / Compact 비교

논리 캔버스는 두 모드 모두 `1920 × 1080`이다. 실제 창 크기는 Godot stretch 정책을 따르되, Compact에서는 정보량과 컨트롤 크기를 별도로 조정한다.

| 영역 | Standard (1920 기준) | Compact (1366/1280 전용) |
|---|---|---|
| 상단 상태 | 62px 높이, 4개 자원 개별 칩 | 54px 높이, 칩 간격 축소, 글자 크기 보정 |
| 캠페인 알림 | 중앙 92px, 인물·적·몬스터 요약 | 중앙 76px, 핵심 제목·요약만 노출 |
| 지도 | `0,0–1920,1080` 전체 캔버스 | 동일 |
| 수비대 레일 | `x24 y786 w1872 h110` | `x16 y820 w1888 h86` |
| 하단 주요 행동 | `x24 y912 w1872 h132` | `x16 y920 w1888 h112` |
| 문맥 드로어 | `x1524 y88 w372 h806` | `x1532 y80 w372 h824` |
| 몬스터 카드 | 176px 폭, 초상 52px | 154px 폭, 초상 44px, 설명 축약 |
| 비주요 정보 | 하단 상태 문장 또는 툴팁 | 툴팁 우선, 상태 문장 한 줄 |

Compact는 Standard를 단순 축소한 화면이 아니다. 작은 창에서 읽을 수 있도록 다음을 별도 적용한다.

- 캠페인 알림의 인물 초상과 부가 출현 목록을 숨긴다.
- 수비대 설명을 한 줄로 줄이고 카드 폭·간격을 줄인다.
- 주요 행동 버튼은 짧은 명칭을 사용하고 글자 크기를 보정한다.
- 문맥 드로어 폭을 줄이되 시설·지침 컨트롤의 최소 클릭 영역을 유지한다.

## 4. 상호작용 계약

- 지도상의 방 선택, 몬스터 드래그, 시설 교체 기능과 콜백은 기존 제품 런타임을 그대로 사용한다.
- 드로어가 열리면 수비대 레일의 폭만 줄어든다. 지도 위치와 크기는 바뀌지 않는다.
- `방어 시작`은 항상 오른쪽 끝의 유일한 금색 주 행동이다.
- `전술·상세`는 드로어를 열고, 드로어 닫기는 지도 상태를 유지한다.
- 레이아웃 선택은 `자동`, `1920 Standard`, `1366/1280 Compact` 세 값으로 저장한다.
- `자동`은 실제 창 너비가 1440 미만이면 Compact를 선택한다.
- 설정의 `취소`는 설정 화면을 열기 전 레이아웃으로 되돌리고, `적용`만 저장한다.

## 5. 구현 금지선

- 지도 좌표, 방 연결, 배치 판정, 전투 AI, 밸런스, 저장 데이터 의미를 변경하지 않는다.
- 구현되지 않은 설정 항목을 활성 컨트롤로 노출하지 않는다.
- 모바일 웹 전용 분기나 세로 화면 UI를 이번 단계에 추가하지 않는다.
- 지도 위 목표 방과 튜토리얼 클릭 대상을 가리는 고정 안내 패널을 추가하지 않는다.

## 6. 완료 기준

- Standard와 Compact에서 지도 노드의 위치·크기가 동일하다.
- 하단 수비대 레일과 주요 행동 바가 겹치지 않는다.
- 열린 드로어가 `방어 시작`을 덮지 않는다.
- 수비대 드래그, 시설 문맥 목록, 되돌리기, 방어 시작의 기존 콜백 연결이 유지된다.
- 설정에서 레이아웃을 미리 선택하고 `적용`/`취소`가 각각 저장/복원된다.
