# v1.2.2 Stage 01 이중 전선 전투 구조 계약

## 1. 상태

- 작성일: 2026-07-29
- 대상 버전: 마왕성 v1.2.2
- 상태: 사용자 결정 완료, Phase A 레이아웃 후보 구현 완료, 제품 활성화 대기
- 우선순위: 그래픽 개편보다 선행
- 적용 플랫폼: Windows 출시판, 데스크톱 Web 테스트판
- 모바일 Web: 범위 제외

이 문서는 기존 Stage 01의 시각 개편 범위를 일시 중단하고, 전투 다양성을 먼저 복구하기 위한 구조 계약이다. `V122_STAGE01_SPATIAL_ART_CONTRACT_2026-07-29.md`에서 공간 구조를 바꾸지 않기로 했던 가정은 이 문서로 대체한다. 새 그래픽은 이 구조가 구현된 뒤 제작한다.

## 2. 변경 이유

현재 Stage 01은 화면상 여러 갈래처럼 보이지만 전투 로직에서는 다음과 같이 동작한다.

- 88개 복도 이동 셀 전체가 `spike_corridor` 한 구역이다.
- 입구·병영·회복실·금고·건설 슬롯·왕좌가 모두 같은 중앙 허브에 연결된다.
- 논리 주 경로는 `외부 → 입구 → 가시 복도 → 왕좌`뿐이다.
- 왕좌행 실제 셀 경로는 가시 함정 칸을 통과하지 않지만, 함정 판정은 복도 전체 room ID에 적용된다.
- 도둑·공병·왕좌 공격대가 첫 교전 지점을 공유하므로 입구 또는 중앙 허브 몰빵이 대부분의 목표를 동시에 막는다.
- 단일 `active_route`와 room 기반 명령·시설 효과가 넓은 복도 전체를 하나의 전술 대상으로 취급한다.

따라서 적 종류와 수치만 바뀌고 전투 장소와 대응법은 반복된다. 그래픽만 교체해서는 해결되지 않는다.

## 3. 고정 구조와 교체 요소

### 3.1 고정 구조

- 정문 진입점 A
- 서비스 침입 균열 진입점 B
- A·B의 고정 통로와 이동 영역
- 두 전선의 전방·후방 구간
- 왕좌 직전 합류 전실
- 내부 관문과 왕좌
- 두 전선 중간의 연결로 건설 예정지

성 구조 편집 기능은 되살리지 않는다. 고정 통로는 플레이어가 끊거나 옮길 수 없다.

### 3.2 교체 가능 요소

- 병영
- 회복실
- 금고
- 감시 초소
- 수호핵
- 빈 건설 슬롯
- 이후 추가될 모든 호환 시설

시설을 옮기거나 교체해도 통로·walkable·collider·적 경로는 바뀌지 않는다. 시설은 고정 통로 옆의 호환 슬롯에 오브젝트와 기능으로 연결한다.

## 4. 확정 토폴로지

```text
외부 A
  ↓
정문 → A 전방 구역 → A 전방 시설 슬롯 → A 연결로 접점 → A 후방 구역 → A 후방 시설 슬롯 ─┐
                                                    ║                                      │
                                                    ║ 건설 후 수비대 연결로               ├→ 왕좌 전실 → 내부 관문 → 왕좌
                                                    ║                                      │
균열 → B 전방 구역 → B 전방 시설 슬롯 → B 연결로 접점 → B 후방 구역 → B 후방 시설 슬롯 ─┘
  ↑
외부 B
```

- A와 B는 왕좌 직전까지 서로 다른 적 전선이다.
- 두 전선은 좁은 단일 초크가 아니라 최소 5×5의 왕좌 전실에서 합류한다.
- 왕좌 문턱은 최소 3셀 폭을 확보한다.
- 왕좌 전실에는 시설 슬롯과 고정 함정을 두지 않는다.
- 최후 방어는 가능하지만 왕좌 전실 몰빵이 항상 최적이 되지는 않아야 한다.

## 5. 전선 비대칭

### 5.1 A 정문 전선

- B보다 짧은 왕좌 직행로
- 좁은 통과 구간과 명확한 전방·후방 교전 구역
- 실제 가시 셀을 밟을 때만 작동하는 고정 함정 구간
- 적이 빠르게 도달하지만 지연과 집중 방어가 쉬운 전선

### 5.2 B 균열 전선

- A보다 약 25% 긴 우회로
- 4~5셀 폭의 넓은 교전 구역
- 적이 퍼질 수 있어 한 몬스터만으로 차단하기 어려운 전선
- 대응 시간은 길지만 시설 목표와 넓은 교전 폭 때문에 병력 분산이 필요한 전선

시설 종류는 어느 전선에도 고정하지 않는다. 전선의 비대칭은 거리·폭·함정·교전 공간으로 만들고, 시설 배치가 그 성격을 추가로 바꾸게 한다.

## 6. 시설 슬롯과 초기 배치

Stage 01의 교체 가능 시설 슬롯은 네 개다.

- A 전방 슬롯
- A 후방 슬롯
- B 전방 슬롯
- B 후방 슬롯

새 게임 초기 배치는 다음과 같다.

| 슬롯 | 초기 시설 |
|---|---|
| A 전방 | 병영 |
| A 후방 | 회복실 |
| B 전방 | 빈 건설 슬롯 |
| B 후방 | 금고 |

이는 시작값일 뿐 고정 역할이 아니다. 관리 단계에서 시설 호환·고유 시설·비용 규칙에 따라 서로 교체할 수 있다.

## 7. 방어 구역과 몬스터 배치

몬스터 배치는 시설 room ID에서 분리하고 다음 고정 방어 구역을 사용한다.

- A 전방
- A 후방
- B 전방
- B 후방
- 왕좌 전실

몬스터 초상화를 방어 구역에 직접 드래그하거나 클릭 배치한다. 시설을 교체해도 몬스터 배치가 임의로 이동하거나 초기화되지 않는다.

방어 구역은 다음을 소유한다.

- 전투 anchor와 이동 가능한 cell 범위
- 기본 배치 정원
- 연결된 시설 슬롯
- 인접 방어 구역
- 소속 전선
- 집결·비상 후퇴 명령 대상

시설 방은 적의 목표와 시설 오브젝트를 소유하지만 몬스터의 주 배치 단위가 아니다.

## 8. 구역 기반 시설 효과

시설의 “근처”는 픽셀 반경이 아니라 방어 구역 연결로 판정한다.

### 8.1 공통 데이터 계약

차후 시설도 같은 규격으로 추가할 수 있어야 한다.

- 효과 범위: `local`, `adjacent`, `lane`, `global`
- 효과 대상: 아군, 적, 시설, 통로
- 발동 방식: 상시, 주기, 명령 발동, 적 진입
- 효과 계열: 배치 정원, 공격, 방어, 회복, 이동, 감속, 탐지, 자원, 목표 유인
- 중첩 방식: 가장 강한 값, 합산, 중첩 불가
- 최대 중첩 또는 상한
- UI 설명과 영향 구역 강조 정보

### 8.2 중첩 규칙

- 같은 효과 계열은 가장 강한 하나만 적용한다.
- 서로 다른 효과 계열은 조합할 수 있다.
- 동일 시설을 여러 개 지어도 같은 구역에서 같은 효과를 단순 합산하지 않는다.
- 명시적으로 중첩 가능한 차후 시설만 데이터에 예외와 상한을 둔다.
- 금고·회복실·수호핵 등 기존 고유 시설 제한은 유지한다.

### 8.3 기본 시설 역할

- 병영: 연결 방어 구역의 배치 정원과 전투 능력 강화
- 회복실: 연결 방어 구역의 몬스터 회복
- 감시 초소: 연결 구역 또는 전선의 적 감속·노출
- 수호핵: 성 전체 방어 효과
- 금고: 경제 시설이자 도둑 목표

건물을 선택하면 영향을 받는 방어 구역을 맵에 직접 표시한다.

## 9. 적 진입과 목표 규칙

- 일반 적은 출현 시 A 또는 B 전선을 확정하고 전투 중 임의로 바꾸지 않는다.
- 출현 5~7초 전에 진입점·전선·목표를 표시한다.
- 일반 왕좌 공격대는 시설 가지로 이탈하지 않고 왕좌 전실로 전진한다.
- 도둑은 금고가 배치된 슬롯의 전선에서 출현해 금고를 노린다.
- 공병은 목표 시설이 배치된 슬롯의 전선에서 출현해 그 시설을 노린다.
- 도둑은 약탈 후 출현 전선으로 이탈한다.
- 공병은 시설 무력화 후 같은 전선으로 왕좌 공격에 합류한다.
- 차후 전선 전환 능력은 명시된 특수 적만 사용할 수 있다.

시설 위치를 바꾸면 특수 적이 들어오는 전선과 예고도 함께 바뀐다.

## 10. 수비대용 내부 연결로

### 10.1 구조

- 두 전선의 전방 시설 슬롯 뒤, 후방 시설 슬롯 앞을 연결한다.
- 시작 시 붕괴·폐쇄 상태로 보이며 이동할 수 없다.
- 일반 적의 공격 경로에는 포함하지 않는다.
- 건설 후 수비 몬스터의 집결·비상 후퇴·일반 이동 최단 경로로 사용한다.

### 10.2 진행과 비용

- DAY 3 관리 단계에서 해금
- 건설 비용: 금화 1,000 + 마력 100
- 건설 즉시 해당 DAY 전투부터 사용
- 한 번 건설하면 해당 세이브에서 영구 유지
- 철거·이전 불가
- DAY 3~4는 연결로 없이도 클리어 가능한 균형
- DAY 5는 연결로를 전제로 하는 첫 본격 양면전
- DAY 5 전투 시작을 코드로 차단하지는 않지만, 연결로 없이 사실상 클리어하기 어려운 구성
- DAY 4 종료 시 DAY 5 위험과 연결로 필요성을 명시적으로 경고

## 11. DAY 1~5 전선 학습

### DAY 1

- A 정문 전선만 사용
- 병영·회복실과 짧고 좁은 함정 전선 학습

### DAY 2

- 초반 A 일반 공격대
- 중반 B 균열 개방 경고와 도둑 출현
- 후반 두 전선이 약 8~10초 겹치는 짧은 양면전
- 연결로 없이 2명/1명 분산 배치를 학습

### DAY 3

- 내부 연결로 건설 해금
- 연결로는 선택 사항이며 즉시 구매를 강요하지 않음
- 소규모 동시 압박으로 집결과 전선 전환 가치를 보여줌

### DAY 4

- 연결로 없이도 명령과 사전 배치로 클리어 가능
- 종료 시 DAY 5 본격 양면전 경고

### DAY 5

- 두 전선의 지속·교차 압박
- 연결로를 사실상 요구하는 첫 전투
- 그래도 전투 시작 자체는 허용

## 12. 명령 대상 계약

- 집결: 방어 구역 선택
- 집중: 적 선택
- 시설 발동: 시설 오브젝트 선택
- 비상 후퇴: 방어 구역 선택

명령은 별도 확인 창을 거치지 않고 전투 맵에서 유효 대상을 직접 선택해 발동한다. 연결로가 완공된 뒤에는 집결·비상 후퇴 경로가 자동으로 연결로를 사용한다.

## 13. 저장·호환 원칙

- 기존 시설 종류와 네 교체 가능 위치는 새 네 슬롯으로 결정적으로 이식한다.
- 기존 몬스터 배치는 가장 가까운 새 방어 구역으로 결정적으로 이식한다.
- 기존 `spike_corridor` 배치는 A 전방 방어 구역을 우선 사용한다.
- 기존 금고·회복실·병영 room ID에 기능을 묶지 않고 새 슬롯의 `facility_role`을 기준으로 복원한다.
- 연결로 건설 여부는 optional save payload로 추가하며 구저장은 `false`가 기본이다.
- 기존 세이브를 불러왔다는 이유만으로 금화·마력 비용을 자동 차감하지 않는다.
- Stage 2~4 확장 소켓은 새 고정 통로와 시설 슬롯을 기준으로 다시 연결하되 기존 진행·시설 종류·성 단계는 보존한다.

## 14. 구현 순서

1. 정확한 셀·socket·instance ID를 가진 이중 전선 layout과 blueprint를 만든다.
2. 단일 `active_route`를 진입점·목표별 복수 route 계약으로 바꾼다.
3. 고정 방어 구역과 몬스터 배치 adapter를 추가한다.
4. 구역 기반 시설 효과와 중첩 규칙을 추가한다.
5. 연결로 건설·저장·비용·경로 활성화를 연결한다.
6. DAY 1~5 entry와 wave 겹침을 새 전선 계약에 맞춘다.
7. 구저장·Stage 2~4 이식을 연결한다.
8. 관련 구조·저장·DAY 1~5 테스트만 실행한다.
9. 구조가 안정된 뒤 Stage 01 그래픽 제작을 재개한다.

## 15. 완료 조건

- A와 B가 왕좌 전실 전까지 별도 논리 전선으로 유지된다.
- 일반 적이 출현 전선을 임의로 바꾸지 않는다.
- 실제 함정 셀에서만 함정이 발동한다.
- 네 시설 슬롯에서 모든 호환 시설을 교체할 수 있다.
- 시설 교체가 walkable·collider·적 route를 바꾸지 않는다.
- 몬스터 배치가 다섯 고정 방어 구역을 사용한다.
- 같은 시설 효과 계열이 같은 구역에서 단순 합산되지 않는다.
- 연결로가 미건설·건설 상태에서 각각 다른 수비 경로를 만든다.
- DAY 1~4는 연결로 없이 진행 가능하고 DAY 5는 연결로의 필요성을 실전에서 검증한다.
- 기존 저장의 시설·몬스터·성 단계가 결정적으로 이식된다.
