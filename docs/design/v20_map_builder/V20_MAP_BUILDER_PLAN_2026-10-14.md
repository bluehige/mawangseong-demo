# 마왕성 맵 개편(1.3.0) — 자유 배치 맵 · 자동 길 연결 · 관전형 전투 화면 기획

이 파일이 왜 필요한가: 현재 맵은 4×4 고정 칸(5×5 방 + 2칸 길)에 방을 끼워 넣는 구조라서 ① 높은 벽이 유닛과 전투를 가리고 ② 꾸미는 재미가 없고 ③ 마름모(쿼터뷰) 땅이 16:9 화면을 채우지 못해 좌우·하단이 비어 보인다. 이 문서는 지금 진행 중인 수정이 끝나면 바로 구현을 시작할 수 있도록 방향·데이터 구조·단계·완료 조건을 고정한다.

- 작성: 2026-10-14, 기준 작업본 `mawangseong-action` (제품 1.2.12, `9f0be3b` 계열)
- 대상 버전: **맵 개편(1.3.0)** — UI 개편·1층 자유 배치·의회 부지 확장 전환을 묶은 1.x 패치. 분기 기준은 8절 참조
- 상태: **확정 (2026-10-14 사용자 승인, 2026-10-15 버전·명칭 결정 반영)** — 8절 참조

## 1. 현재 문제 진단 (실제 캡처 기준)

| 문제 | 원인 | 근거 |
|---|---|---|

## 2. 핵심 방향 (한 줄 요약)

> **"땅(부지)은 화면 모양에 맞춘 직사각형, 건물은 자유 배치, 길은 자동, 벽은 뒤쪽만 높게."**

### 2-1. 시점: 쿼터뷰는 유지, 대신 '화면에 맞춘 부지' + '벽 잘라내기'
- 기존 쿼터뷰 그림 자산(128×64 타일, 몬스터 4방향 스프라이트)을 버리지 않는다. 시점을 탑뷰로 바꾸면 전 자산 재제작이 필요해 비용이 너무 크다.
- **부지 모양 변경**: 격자 자체는 쿼터뷰 격자 그대로 쓰되, "건설 가능 칸"을 **화면에서 보았을 때 가로로 긴 직사각형 안에 들어오는 칸**만으로 정한다(=화면 정렬 부지 마스크). 부지 밖은 동굴 바위·용암·수정 같은 배경 지형으로 채워서 화면 끝까지 그림이 꽉 찬다. 이러면 귀퉁이 검은 공간이 사라진다.
- **벽 잘라내기(컷어웨이)**:
  - 부지 맨 뒤(화면 위쪽) 경계 = 높은 동굴 절벽 벽 (깊이감 담당)
  - 건물의 뒤쪽 두 면(북·서) = 보통 높이 벽
  - 건물의 앞쪽 두 면(남·동, 카메라 쪽) = **무릎 높이 낮은 턱**으로만 그림
  - 길(복도) = 벽 없음, 바닥 가장자리 턱 + 횃불·난간 장식만
  - 유닛이 벽 뒤에 있으면 실루엣(외곽선) 표시 — 안전장치
- 결과: 어떤 위치에서도 방 안 전투가 보이고, 벽은 "분위기용 배경"이 된다.

### 2-2. 배치: 정해진 부지 안에 건물을 자유 배치
- 부지 크기(1단계): 화면 정렬 직사각형 약 **30×20 칸**. 마왕성 등급(`castle_grade_rules.json`)이 오를 때 부지가 넓어진다(확장 = 성장 보상).
- 고정 건물 2개: **입구**(부지 왼쪽 가장자리 고정), **왕좌/마왕성 심장**(부지 안쪽 뒤편, 이동 가능하지만 삭제 불가).
- 배치 건물: 병영, 회복 둥지, 보물실, 함정방, 시설류… 기존 `room_blueprints.json` 의 방을 재사용하되 크기를 다양화(3×3 / 3×5 / 5×5 / 5×7).
- 각 건물은 **문 위치(소켓)** 를 데이터로 가진다. 회전은 2방향(가로/세로)만 우선 지원.
- 배치 규칙: 건물끼리 1칸 이상 띄움(길 자리), 부지 밖 금지, 입구/왕좌 경로를 끊는 배치는 빨간색 미리보기로 거부.

### 2-3. 길: 자동 연결 (사용자는 건물만 놓는다)
- 건물을 끌어다 놓는 순간(드래그 중에도) 자동 길 계산 → 반투명 미리보기 표시.
- 알고리즘:
  1. 입구 문 → 왕좌 문을 A* 최단 경로로 먼저 연결(주 도로, 폭 2칸).
  2. 나머지 건물 문을 "이미 있는 길 네트워크"까지 가장 가까운 순서로 A* 연결(가지 도로, 폭 2칸). 비용: 직진 선호, 꺾임 +비용, 건물 옆면 바로 붙기 +비용, 기존 길 재사용 −비용 → 깔끔한 큰길 + 가지 형태가 나옴.
  3. 결과 칸 목록을 기존 `CorridorTopologyBuilder.build()` 에 `visual_patches` 로 넘겨 바닥/턱 자동 타일 생성(기존 코드 재사용).
  4. 전투 이동 그래프(`ModuleGraph`/`RoomGraph`)는 길 칸 연결에서 자동 생성.
- 미로 꼼수 방지: 길은 항상 "자동 최단"으로만 생기므로 플레이어가 지그재그 미로를 만들 수 없다. 대신 **건물 위치로 적의 동선 길이와 갈림길을 설계**하는 게 전략이 된다.
- (2차) 길 위 1칸 슬롯에 함정·바리케이드 설치, 수동 우회로 그리기는 이후 확장.

### 2-4. 꾸미기: 성능과 무관한 장식 + 약한 보너스
- 장식 1×1 오브젝트(횃불, 깃발, 해골 더미, 수정, 동상, 용암 화로 등)를 부지 빈칸·길 가장자리에 자유 배치.
- 장식은 "위압감" 점수로 합산 → 기존 성 등급 점수에 소량 반영(전투 수치에는 직접 영향 없음 → 밸런스 안전).
- 바닥 테마(돌/뼈/자수정) 칠하기는 2차.

### 2-5. 관전: 전투를 보기 좋게
- **기본 전투 줌**: 유닛 높이 64~96px가 되게(현재의 약 2배). 맵 전체는 미니맵으로.
- **관전 카메라(자동 연출)**: 가장 치열한 지점(피해량·스킬 사용·왕좌 위협)을 점수화해 부드럽게 따라감. 유닛 클릭 = 추적, 휠/드래그 = 수동(5초 무조작 시 자동 복귀). 설정에서 끌 수 있음.
- **HUD 슬림화**: 하단 3개 패널(운영 지침/명령/배속)을 한 줄 높이로 접고, 펼치기 버튼. 미니맵은 오른쪽 아래.
- 적 진입로(입구→왕좌 주 도로)는 전투 중 은은한 빛 화살표로 표시.

## 3. 결정이 필요한 3가지 (권장안 표시)

1. **부지 크기·확장** — 권장: 시작 30×20, 성 등급마다 가로 +6칸. (대안: 고정 크기)
2. **길 폭** — 권장: 2칸(전투가 잘 보이고 몬스터 2마리가 나란히 막을 수 있음). (대안: 1칸 좁은 길 = 막기 쉬움, 보기 어려움)
3. **기존 세이브** — 권장: 1.2 세이브의 고정 배치를 새 부지 좌표로 자동 변환(같은 방 구성 유지). (대안: 맵 개편(1.3.0)에서 맵만 초기화)
