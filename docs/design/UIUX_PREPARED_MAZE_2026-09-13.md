# 성장형 고정 미궁 — 구현 계약

작성일: 2026-09-13. 대상: 1.2.6 기반 UI·UX 작업본, 미출시. 브랜치: `codex/v126-uiux-u0-u3`.

## 사용자와 확정한 8개 결정

1. 벽의 외형만 바꾸지 않고 실제 갈림길과 우회로를 새로 설계한다.
2. 플레이어는 준비된 미궁에 시설·몬스터를 배치한다. 자유 굴착·통로 편집은 추가하지 않는다.
3. 고정된 방 위치를 유지하며 성 성장 단계에 따라 새 방과 길이 열린다.
4. 기존 적 목표 선택 결과를 사용하고, 방어 준비 중 실제 예상 진입 경로를 보여준다.
5. 시설은 방 안의 기존 지정 건설 구역에만 설치한다.
6. 현재 사선 시점을 유지한 지붕 없는 실내 단면으로 표현한다. 앞벽을 낮추고 실제 연결부에 열린 아치를 둔다.
7. 초반에는 한 진입구로 익히고 후반에는 주요 진입로 2~3개 규모를 지향한다. 현재 구현은 성장 후 정문·측문 두 진입구다.
8. 기존 DAY 3 / 금화 1,000 / 마력 100 연결로는 정해진 **수비대 전용 샛문 복구**로 유지한다.

이 합의는 최초 V2의 기존 경로 보존 범위를 미궁 구조에 한해 확장한다. 비용·해금·시설 콘텐츠·적 수치·저장 형식을 임의로 바꾸는 승인은 아니다.

## 성장과 실제 보행

새 게임 기본 레이아웃은 `prepared_maze_growth_01`이다. 정적 JSON과 두 꺾임 회랑 모듈을 사용한다. `tools/BuildPreparedMazeLayout.py`는 이 고정 배치를 재작성하는 제작 도구이며 게임 실행 시 지도를 생성하지 않는다.

| 단계 | 열리는 구조 | 실제 진입 |
|---|---|---|
| 동굴 | 가시 길목에서 왕좌 회랑과 보물고 방향으로 분기 | 정문 하나 |
| 성 | 측문, 측면 합류 회랑, 감시초소 및 보물고 쪽 순환 연결 | 정문·측문 |
| 요새 | 기존 결계 핵·두 번째 슬롯 및 외곽 연결 | 두 진입구 유지 |
| 성채 | 기존 정예 주둔지·세 번째 슬롯 및 상부 우회 연결 | 두 진입구 유지 |

기존 방의 좌표는 성장 시 이동하지 않는다. 선택형 심장 방은 기존 update3 해금 조건으로만 열린다. 연결된 소켓과 실제 보행 타일이 같은 통로를 정의한다. 정문과 측문을 바로 잇던 초기 연결은 측문 적이 정문으로 되돌아가는 최단 경로를 만들었으므로 제거했다. 현재 측문→왕좌 경로는 측면 합류 회랑을 실제 통과한다.

`combat_topology.lanes.route`도 실제 연결을 따라 기록해 기존 방→수비 구역 매핑이 계속 작동한다. 적 이동은 기존 런타임의 타일 경로 탐색을 사용한다. 샛문 빈틈은 공용 보행 타일에 포함하지 않는다.

## 조작과 정보

- 전술 도구함에서 현재 침입 계획의 진입구·목표별 그룹을 선택한다. 표시되는 적 종류와 수는 실제 전투 준비 스냅샷에 근거한다.
- 선택한 경로만 가는 선과 방향 화살표로 그린다. 방 중심을 직선으로 잇지 않고 실제 타일 보행 경로를 사용한다.
- 이 경로는 준비 시점의 예상이다. 교전·시설 상태·목표 변경 후의 이동을 보장하지 않으며 UI에도 이를 표시한다.
- 몬스터 카드를 실제 수비 길목에 끌어 놓거나 Enter로 선택한 뒤 길목을 클릭한다. 선택 중에만 기존 5개 수비 구역과 정원이 표시된다.
- 기존 `defense_zone_id` / `assigned_defense_zone_id`가 실제 전투 생성 위치를 결정한다. 소속 시설 `room`은 보존한다. 시설 변경과 수비 위치 변경을 혼동해 수용량이나 콘텐츠를 늘리지 않는다.
- 시설을 통한 배치와 길목 직접 배치 모두 같은 기존 수비 구역 정원을 검증한다. 같은 위치 중복 입력은 이전 Undo를 덮어쓰지 않는다.
- 준비 화면의 몬스터 위치와 실제 전투 생성 위치는 같은 배치 계획·방 안 배치점·보행 타일 보정을 사용한다.
- 샛문은 기존 실행 경로로 비용을 한 번만 소비하고 아군 이동에만 적용한다. 기존 Undo로 문 상태와 두 자원을 복구한다.
- 일반 전술 진입에서는 상세창을 닫고, 방 선택 또는 튜토리얼의 방 지침 요구 때만 해당 상세창을 연다.
- 시설 건설은 기존 카드→고스트→드롭 후보→검토→확정/취소 흐름을 유지한다.

## 자산과 가독성

기존 시설과 성 단계별 자산은 그대로 재사용한다. 앞벽은 기존 낮은 앞가림 자산으로 표현하고 바닥 밝기를 조정했다. 새 열린 아치 2방향은 GPT 내부 이미지 생성 결과의 실제 RGBA PNG를 원본 그대로 사용한다. 문 가운데도 투명하며 배경 제거·로컬 픽셀 편집은 하지 않았다. 아틀라스 구역과 균등 배율로 연결부에 그린다.

## 저장·밸런스 경계

기존 출시 레이아웃 `stage01_dual_front_candidate_01`은 별도 등록해 보존한다. 저장된 레이아웃 전체를 복구하며 옛 저장을 새 미궁으로 강제 이동하지 않는다. 1.2.6 이전 저장 마이그레이션 목적지도 기존 출시 레이아웃으로 유지한다. 새 미궁 저장에는 새 레이아웃 ID와 기존 저장 필드가 기록된다.

DAY 1~5 파동 별칭은 기존 출시 레이아웃의 파동 카탈로그를 참조한다. 적 수·수치나 보상·시설 비용을 새 지도 때문에 바꾸지 않는다. 그러나 **동선 길이와 합류 시점 변화는 전투 난도에 영향을 줄 수 있으므로**, 전체 캠페인 승패 밸런스가 검증됐다고 주장하지 않는다.
