# 성장형 미궁 석조 벽 개선 — 2026-09-13

## 승인과 범위

사용자는 방 자체를 공간으로 표현한 고정 미궁을 유지하면서, 벽을 더 미궁답게 만들고 꺾인 면이 깨져 보이는 문제를 고치도록 승인했다.
작업흐름: UIUX-V2-MAZE-MASONRY-20260913. 기반은 미출시 UI/UX 작업본의 1.2.6이며 새 제품 버전이나 출시를 뜻하지 않는다.

## 최종 구현

- 실제 닫힌 wall_edges로 두께 있는 석조 입체를 계산한다. 공유 꼭짓점은 단일 높이를 소유하여 안/바깥 모서리, T 접합, 벽 끝, 높은 벽과 낮은 벽의 단차를 연결한다.
- 북/서 뒷벽 높이는 112, 동/남 앞벽은 36의 월드 기준 높이로 시작해 기존 지도 배율을 곱한다. 벽 두께는 타일의 0.4배다.
- 생성된 석재를 윗면과 측면에 투영한다. 면 경계의 얇은 밝기 차이로 돌 상단을 구별하며 내부 윗면 분할선은 그리지 않는다.
- 높은 면은 기존 정적 뒷벽 순서, 낮은 면은 기존 전면 레이어를 사용한다. 전면 벽은 낮은 불투명 석조로 발 부분만 가린다.
- 성장이 활성화한 실제 시설 방/왕좌/심장실에 인접한 연결로에만 열린 아치를 놓는다. 단순 통과 복도에는 반복 아치를 두지 않는다.
- 지정된 방과 꺾임마다 가장 가까운 실제 닫힌 뒷벽에 최대 한 개의 따뜻한 횃불을 단다. 장식에는 전투 범위나 효과를 추가하지 않는다.
- 구조는 지도 갱신 때만 다시 계산한다. 카메라 확대나 매 프레임 다시 그리기로 재계산하지 않는다.

미궁 연결, 적의 목표 및 경로, 수비대 샛문 비용·해금, 건설 구역·비용·검토·Undo, 세이브 형식과 제품 콘텐츠는 변경하지 않는다.
벽 높이와 재질은 외형이며 건설 영역이나 통행 판정을 넓히거나 줄이지 않는다.

## 직접 검사

UIUXMasonryTest는 기존 미궁 직접 테스트를 확장한다. 10개 접합 구성에서 윗면의 빈틈·중복, 보이는 측면의 총면적, 단차, UV 범위와 열린 문을 검사한다.
역방향 단차에서 카메라 뒤를 향하는 면은 그리지 않는다. 보이는 단차의 누락을 검사하며 보이지 않는 면을 필수 렌더 대상으로 오인하지 않는다.
실제 4단계 지도에서는 통행 셀의 중심, 원본 배치 보존, 전후 레이어, 실제 확대 버튼, 렌더 캐시를 검사한다.
Windows 1920×1080/1280×720 × 글자 90/100/115% 및 기존 미궁 저장·배치·샛문·전투 검사를 함께 수행한다.
건설 및 전투 명령은 기존 UIUXBuildPlacementTest와 UIUXCombatInteractionTest를 별도로 실행한다.
최종 수치와 SHA는 해당 세션 핸드오프에 기록한다.
