## 실제 정보와 시안의 경계

- 요청된 `tmp/v1213_uiux_audit/*.png` 경로가 없어, [보관된 실제 캡처](../audit/)의 JPG를 대신 사용했다. 읽기 전용으로 문서·관련 코드·데이터·초상을 확인했으며 git 명령과 게임 빌드·실행은 수행하지 않았다.
- 관리 지도는 실제 캡처와 B 관리 시안을 참고한 일러스트다. 그림 속 장식·방 위치·화살표 좌표를 새 지도 구조나 설치 판정 데이터로 이식하지 않는다. 유효 위치·범위·배치 수는 U5에서 실제 지도 상태에 연결한다.
- 03의 **설치 수 0/— · 상한 확인 필요**는 확인되지 않은 전체 설치 상한을 임의 숫자로 만들지 않기 위한 미정 표시다. 감시 초소의 **배치 0/3**은 동료 정원이며 설치 최대 수와 다르다. 카드 비용은 현재 `_facility_base_definition()`의 감시 100금화/50마력, 병영 100금화/2식량, 보물 120금화, 회복 80마력을 사용했다.
- 왕좌 1500 HP는 실제 자료 값이다. 보물실은 수치를 붙이지 않은 아이콘·바로 표시했다. 이는 시각적 위치 제안이며, IA §3에 따라 실제 보호 목표·현재 HP 자료가 있는 경우에만 U5에서 연결한다.
- 04는 DAY1의 푸딩·핀 고정과 곱 드래그 미리보기다. 카드의 HP는 기본 종족 데이터의 180/140/120을 사용한 무피해 상태를 가정했다. 현재 실제 게임에서 그 상태가 실행됐다고 주장하지 않는다.
- 05의 적 ×6은 DAY12 실제 캡처의 **전체 혼합 병력 수**다. 종류별 수는 미확인이므로 합계 아이콘을 사용했다. 반복 화살표는 정적 PNG에서 이동 방향을 나타내며 실제 애니메이션은 구현하지 않았다.
- 06은 설치 비용을 차감한 DAY1 상태의 강화 잠금 예시다. 실제 규칙의 Lv.1→2, HP 380→460, 정원 3→4, 비용 90금화/30마력, DAY07 해금을 사용했다.
- 07은 DAY12 실제 푸딩 Lv.5·EXP20·HP260/공격20/방어12를 참고했다. 훈련 EXP+20 미리보기는 20/170→40/170, 능력치 +0이며 **현재 장 상한 Lv.5 도달**로 비활성이다. 구매 가능·능력치 상승 상태를 꾸며내지 않았다. “영구”는 현 진행에서 날짜가 지나도 남는다는 뜻이다. 훈련은 다음 전투 준비 버프를 자동 지급하지 않는다.
- 08의 레벨·날짜·장 시작·자원 체크는 DAY12 캡처와 해당 전직 규칙에 맞춘 비교 상태다. 누적 승급 인원은 확인되지 않아 **확인 필요**로 남겼다. 전직 조건에 없는 유대 기준을 추가하지 않았다. 합동기는 별도 해금이며 전직으로 자동 해금되지 않는다.
- 09의 명령 CP와 ×1/×1.5/×2/×3은 실제 전투 캡처에서 가져왔다. 유닛 HP바는 미확인 수치를 붙이지 않았다.
- 10의 피해133·보호3회·보상198/60/15·푸딩EXP30/50·곱EXP20/50은 실제 DAY1 결과 캡처 값이다. 집중성장 전22는 결과30에서 실제 선택 보너스8을 뺀 비교값이다. 관찰되지 않은 성과는 **—(미확인)**이며 0점이라는 뜻이 아니다. “성장 확인”과 명시적 다음 DAY를 유지하며 훈련은 다음 준비의 미리보기로만 연결한다.
- 11의 미만남 동료는 실루엣·역할·다음 회차 계약 조건으로만 표현했다. 실제 계약·편성에는 기존 회차·후보·선택 수·해금 검사를 적용해야 한다. 엔딩·미해금 기억 본문은 노출하지 않았다.
- 12는 사용자 요청의 **화면/일반/오디오/전투 4탭** 시안이다. IA의 조작·접근성과 대화·안내는 “일반” 안의 하위 항목으로 묶는 배치를 가정했다. 실제 일반 설정의 전체/핵심만/끄기, 별도 연습, 도움말 기록 초기화와 적용/취소를 유지한다.
