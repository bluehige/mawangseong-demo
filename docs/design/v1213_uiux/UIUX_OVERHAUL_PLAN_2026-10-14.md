# 마왕성 UI/UX 전면 개편 계획 (2026-10-14)

이 파일이 왜 필요한가: 사용자 지시 "덜 만든 게임 같은 UI를 제대로 만든 게임의 디자인과 형태로, 복잡한 UX도 제대로 수정"을 실행 가능한 단계로 고정한다. 기존 체크리스트(`docs/plans/V1213_FIX_CHECKLIST_2026-10-14.md`)의 2~4단계 화면 항목은 이 개편 안에서 함께 처리한다.

## 1. 목표 (완료 판단 기준)
1. **완성된 게임처럼 보인다**: 기본 Godot 컨트롤·단색 사각 패널 노출 0, 모든 화면이 같은 디자인 시스템(패널·버튼·아이콘·글꼴·색)을 사용.
2. **글자보다 아이콘**: 반복되는 개념(자원, 명령, 메뉴, 배속, 적 종류, 상태)은 아이콘+숫자, 설명은 툴팁. 빈 툴팁 0.
3. **화면은 넓게, UI는 얇게**: 전투 준비·전투 화면에서 던전이 화면 80% 이상. HUD는 상단 자원 바 + 하단 아이콘 독 + 접이식 상세 패널.
4. **한 화면 = 한 결정**: 한 화면에서 플레이어가 하는 결정이 1~2개로 분명. 모드·탭 중복 제거.
5. **핵심 루프 클릭 수 감소**: DAY 시작→배치→전투→결과→성장→다음 날 동선 클릭 수를 진단치 대비 30% 이상 감소(0013 진단 후 목표 확정).
6. 1920×1080 기준, 1280×720·2560×1080에서 잘림 0, 한국어/English/简体中文 잘림 0.

## 3. 운영 원칙 (오케스트레이션)
- 디자인(U0~U3)은 코드 수정과 분리돼 병렬 진행. 구현(U4~U5)은 한 번에 한 명의 writer, 화면 단위 커밋.
- 기존 UI는 하드코딩 좌표(`Rect2(...)`) 위주일 가능성이 큼 → U4에서 공통 컴포넌트로 바꾼 뒤 화면을 교체(화면마다 새로 하드코딩하지 않음). 0013 진단 결과로 확정.
- 진행 중인 0010(공통 글꼴·툴팁·언어·타이틀 우선 표시·대화 번호 제거·21:9)은 유지. 툴팁·언어·흐름 관련 결과는 그대로 쓰고, 옛 레이아웃의 글꼴 확대분은 U5에서 새 화면으로 대체.
- 게임 로직·밸런스·세이브 구조는 바꾸지 않는다(UI 교체만). 필요한 경우 별도 항목으로 사용자 확인.
- 던전 맵 구조 자체는 v2.0 자유 배치 맵 계획(`docs/design/v20_map_builder/`)에서 처리. 이번 개편은 맵 주변 HUD만.
