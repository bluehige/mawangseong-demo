# 1.2.11 변경점 — 비공개 검토판

공개 배포 전 검토용입니다. 현재 공개 Steam 빌드는 부모 조회 기준 1.2.10이며, 아래 내용은 이번 1.2.11 개발 빌드에 적용됐습니다.

1. 전투 자막이 설정 복귀와 배속에서도 읽히도록 개선했습니다. 중요한 이야기 문장은 별도 대화 표시로 보존합니다.
2. ESC와 화면 메뉴에서 계속·저장·불러오기·설정·타이틀·종료에 접근할 수 있습니다.
3. 체크포인트의 DAY·저장 시간과 진행 손실 범위를 표시합니다. 전투 중간 저장은 지원하지 않으며 마지막 체크포인트로 복원합니다.
4. 대화 로그에서 이전 문장을 읽는 동안 자동진행을 멈춥니다. 로그는 읽기 전용이며 이번 실행에서 표시한 문장을 보관합니다.
5. 승급·활성 왕관 모습으로 대답하도록 대화 초상을 맞춥니다. 매복대장의 첫 강화 베기와 실제 피해를 표시하고, 새 설정은 선택한 배속을 유지합니다. 기존에 배속 유지 옵션을 끈 설정은 존중합니다.

타이틀·설정·공지 및 Windows 빌드 정보는 1.2.11/1.2.11.0입니다. 처음 공지를 확인하면 반복 표시하지 않으며 타이틀에서 재열람할 수 있습니다.

Steam Auto-Cloud의 실제 두 PC 동기화 검증은 아직 NOT_RUN입니다. 이번 공지는 검증되지 않은 Cloud 완료나 승급 밸런스 개선 완료를 주장하지 않습니다. 개발자 지원병 추격 시제품은 기본 비활성이며 기존 해금일·공격력·적 수·웨이브 시간은 바꾸지 않았습니다.

## 이전 버전 기록

- **1.2.10:** 간체 중국어 지원판과 이후 같은 버전 핫픽스. 부모 Steamworks 조회에서 공개 Build25808943, 설명 `v1.2.10 same-version hotfix`, 소스 `515ed745d4ce731f7bafb31ee1f9381470794d72`를 확인했습니다. 이름/첫날 UI와 배속 유지 옵션 개선이 포함돼 있으며 이번 브랜치에서 보존했습니다. 기존 날짜별 handoff와 PRODUCT_VERSIONING의 1.2.10 항목은 그대로 남겨 둡니다.
- **1.2.9 및 이전:** 기존 공개 태그·바이너리·역사 문서를 보존합니다. 이번 작업은 그 자료를 다시 버전 표기하거나 교체하지 않습니다.
