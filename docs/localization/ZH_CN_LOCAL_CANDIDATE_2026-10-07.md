## 원어민 교정과 SC 자형을 구분

**문장·말투 교정:** 전체7,493개 슬롯과 상점/홍보 문구를 중국어 원어민이 읽는 절차는 미완이다. 인명 음역, 기술명 이해도, 행정 코미디·말장난, 후반의 감정 변화, 선택 분기의 의미와 톤, 후보 제목을 확인해야 한다. 특히 `集中` 수치/명령과 `集火` 설명을 구분해 읽을 수 있는지 점검한다. 기계 토큰 검사나 모든 대사 표시 성공은 이 절차를 대체하지 않는다.

**SC 글꼴 자형:** 묶음 `NotoSansCJKkr-Regular.otf`는 OFL 자산이며 현재 중국어 텍스트의 한자·중국어 문장부호1,793종을 모두 포함한다. 실제1280×720 창과1080p 요청 창(Windows 실제 캡처1886×1061)에서 tofu와 검출 가능한 clipping은0건이다. 별도 최종 후보 EXE의 제목 부팅 캡처는 정확히1920×1080이다. 다만 패밀리 기본 디자인은KR이며 SC 전용 패밀리를 새로 취득하거나 지역 자형 전체를 별도 감사하지 않았다. 글자 존재와 중국어권에서 선호하는 획/부수·지역 자형의 일치는 다른 검사다. 骨·令·直·门·关·这·述 같은 대표 글자와 제목/설정/대화의 작은 크기 가독성을 중국어 독자가 확인해야 한다. SC 전용 폰트를 선택하려면 정확한 기존 자산 또는 다운로드 대상·라이선스를 먼저 확인하고 사용자 결정 뒤에만 연결한다.

**시각 취향:** 로고의 두 줄 제목, 금색/보라색 윤곽, 작은 캡슐에서의 글자 크기, promo 슬로건 승인도 미완이다. 생성 원본은2개를 보존하고, 실제 native alpha와 Steam 목표 크기를 검사했다. 기존 한·영 그래픽은 바꾸지 않았다.

## 공개 전 남은 일

1. 문장·자형·홍보 후보 검토와 새 출시 버전을 확정한다.
2. 허용된 Git writer 환경에서 전용 브랜치·명시적 파일 커밋을 만들고 실제 최종 SHA로 필요한 관련 검사를 기록한다. 현재 이 실행 환경의 Git 관리 영역은 읽기 전용이다.
3. 별도 공개 지시가 있을 때 후보 빌드, 지원 언어, 언어별 설명 이미지3개·대체 텍스트를 Steam에 반영하고 확인한다. 현재 상점 JSON은 미게시 초안이며 기존 한·영 본문은 보존했다.
4. 출시 버튼·default·태그·Git 공개 push는 이 작업에서 실행하지 않았다. 내일 출시 승인과 후보 현지화 승인 상태를 혼동하지 않는다.

Library의 현재 필수 도우미 실행은 `python3` 명령 부재로 실패했다. 새 설치나 대체 전송은 시도하지 않았고 Library ID는 없다. 검토 이미지는 위 실제 파일 경로로 전달한다.
