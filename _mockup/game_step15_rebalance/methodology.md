# B04 연속 캠페인 측정 방법

기준은 0118 위 `0a90971c970ac2a65ed6c6661b5c9d66a3e07704`, 브랜치는 `codex/v130r-defense-layout`이다. 로컬 main이 없어 캐시 origin/main의 정책을 읽었으며 원격 최신성은 확인하지 않았다. 공개·원격 작업은 하지 않는다.

## 주 측정

고정 시드 130401~130410 각각 타이틀의 새 게임부터 시작한다. 프롤로그·이름·대사·필수 특화·승급·원정·DAY29 선언과 정산을 제품의 실제 경로로 통과한다. DAY를 주입하거나 동료를 미리 해금하지 않는다. 레벨·EXP·유대·전직·HP·금·마나·식량을 직접 보충하지 않는다. 정산 보상과 레벨 성장은 B02가 연결한 실제 전투 신호를 사용한다.

첫 3일은 기본 x1, 제품에서 해금된 뒤 x3 버튼에 해당하는 속도를 사용한다. 전투는 실제 60Hz 이동·판정·상태·스킬·투사체 tween을 순서대로 처리한다. 화면 작업만 생략하는 시험 하위 클래스를 사용하며, 실제 렌더 표본을 별도로 확인한다. 이 자동 입력은 출시 EXE에 대한 Computer Use 수동 검수가 아니다.

최종 완주는 재도전 없이 첫 패배에서 종료하는 새 게임 10회로 검증한다. 날짜 곡선의 주 분모는 시작한 10회이며 실제 도달 회차 기준도 병기한다. 패배 HP는 0이며 CSV의 미도달 전투값은 빈칸으로 남긴다. 시작 10회 지표는 중도 종료를 이후 생존 실패·HP 0인 흡수 상태로 집계한 출발 집단 지표이며 가상의 전투 관측이 아니다. 주판정 분모와 완주 정책은 `day_curve.md`에 명시한다.

초기 진단군은 0112의 정상 재도전 1회를 계승했다. 같은 날 두 번 지면 종료했으며 HP 복구는 제품의 실제 재도전 버튼 경로만 사용했다. 이 군은 누적 난도 원인 분석용으로 보존하고, 최종 재도전 없는 7/10 달성 근거는 실제 `retries=0` 실행만 허용한다. 재도전 허용군의 첫 패배 이전 경로를 따로 집계한 `first_life_curve.json`은 참고용 파생값이며 최종 실행을 대신하지 않는다.

건설 추천 서비스가 별도로 없어 시험 정책을 고정했다. 승인 도면의 빈 부지를 결계핵·병영·회복 둥지·감시탑·미끼 금고 순으로 구매하고, 추천 배치 인원 또는 선호 시설 점수가 좋아지는 강화만 구매한다. 마나 60을 남기고 실제 해금·부지·수량·비용·잔액 검사에 통과한 구매만 적용한다. 필수 선택은 실제 가능한 첫 선택지로 고정하며, 기본 수비 지침과 제품의 추천 자동 배치를 사용한다.

DAY29는 전투 없이 준비 결산 후 DAY30으로 이어간다. DAY30 승리는 정상 엔딩 완료 플래그까지 확인한다. 테스트 씬의 기존 저장 비활성 규칙을 보존한다. 격리 APPDATA 안에서 실행하고 시험용 런타임 사본만 기록하므로 사용자 저장 원본을 읽거나 수정하지 않는다. 정식 저장·이어하기 G01의 통과 근거는 아니다.

## 배치 비교

주 측정에서 실제 도달한 날짜의 전투 진입 직전 사본을 보관한다. 같은 사본의 HP·자원·건물·동료·성장을 복원해 추천, 병영/결계핵/옥좌 집중, 최종선 집중, 1차선 집중을 비교한다. 네 조건에 같은 시작 난수 시드 `seed + DAY × 1000`을 적용하고 첫 전투만 비교한다. 이후 난수 소비는 각 배치의 실제 전투에 따른다. 배치별 고유 좌표·부지 수용량·보유 동료·식량 유지비를 검사한다.

집중①은 실제 구매한 고유 ID와 무관하게 병영·결계핵·옥좌 **종류** 전체를 허용한다. 집중②/③은 실제 수비 칸의 선 구분을 사용하며 일부 칸만 해당하면 원래 슬롯 번호로 되돌린다. 선호 시설만 채우고 빈칸을 남기는 약한 비교를 피하기 위해, 남은 실제 보유 동료를 레벨 순으로 남은 합법 칸에 넣는다. 생산 식량과 실제 건물 정원을 넘기지 않는다.

이는 동일 성장 상태에서 전략 차이를 보는 보조 측정이다. 날짜별 임의 레벨·예산을 만든 0104/0106 방식으로 주 곡선을 대체하지 않는다. 미도달 상태는 배치 비교에서도 제외하고 분모를 표시한다. 추천 우위는 F/E/D/C 등급별 전체 승률과 패배 0을 포함한 평균 옥좌HP가 모두 집중 이상일 때 통과한다. 기존 문제일 DAY20·21·26은 날짜별로도 같은 조건을 요구한다. 모든 날짜별 세부값을 함께 공개한다.

## 탐색과 제외

`tmp/v130r_b04/` 아래 baseline·opening·routing·probe·path_pressure·late_routes·paired_canary·paired_guards 등의 기록은 원인 조사와 후보 탐색이다. 과거 소스·체크포인트 재개·단일 시드·잘못된 시험 설정을 최종 새 게임 10회 근거에 합산하지 않는다. `campaign_v1`은 빈 시설까지 강화해 마나를 고갈시키던 시험 정책 때문에 중단했다.

`campaign_v2`는 3번째 회차의 DAY25 결과 기록 중 시험 도구가 해제된 지도 화면을 참조해 중단됐다. 그 이전 자연 연속 관측은 탐색 자료로만 남긴다. 또한 옛 진입 사본은 새 지도 메타데이터를 보관하지 않아 구매·강화한 지도 대신 기본 도면으로 복원되는 것을 확인했다. 따라서 옛 진입 사본을 사용한 배치·DAY15/30 후보 비교는 최종 채택 근거에서 제외했다. 최종 사본은 `approved_map_session`을 포함하며, 복원한 건물·강화·함정·자원·식량·전문화·날짜를 필드별로 검사한다. 탐색에서 시도했던 DAY30 ATK 계수 변경도 원복했다.

진입 당시 남아 있던 0115/STEP10C 미커밋 웨이브 원문은 `superseded_0115_waves.json`에 보존했다. 이 원문을 0118 커밋으로 복원한 변경과 새 B04 변경을 `changed_values.md`에서 구분한다. 최종 채택 라벨, 입력 해시, 실제 검사 수, 엔딩 시드와 원시 로그 해시는 `evidence_manifest.json`에 기록한다.

## 최종 전 예비 검증

`campaign_v6`는 추천 UI의 방어 자격 누락을 발견해 중단했다. 기존 UI는 DAY2에 미보유 로로를 배치하고, 원정에서 `defense_enabled=false`로 등록된 이후에도 계속 배치했다. 새 지도 추천에도 기존 본편의 `_monster_available_for_defense`를 연결했으며 명시적인 `--unlock-all` 시험 모드만 예외다. 몬스터 수치와 합류 조건은 변경하지 않았다. v5·v6 및 이전 사본의 밸런스 결과는 최종 근거에서 제외한다. v6은 정상 엔딩 파일 기준 5회 중 4회 완주·1회 DAY30 패배 뒤, 6번째 회차 진행 중에 중단했다(`diagnostic_eligibility.json`). 최종 완주 수는 DAY30 승리와 엔딩 파일을 함께 대조한다.

수정 후 `legal_smoke2`는 실제 새 게임 DAY1~2에서 로로를 임의 등록하지 않고 보유 동료 3명으로 통과했다. 최종 주 측정은 `campaign_v7`의 새 게임 10회이며, 매 배치에서 사전 보유와 방어 자격을 검사한다.

최종 집중 비교는 제품의 탱커·원거리·지원 우선 역할을 유지한 뒤 실제 레벨 순으로 배치한다. 제한된 정원을 저레벨 동료가 먼저 차지해 고레벨 동료를 제외하는 약한 기준을 피한다. 남은 합법 칸도 실제 레벨 순으로 채우며, 동료의 레벨이나 능력치는 바꾸지 않는다. 이 강화 이전의 예비 비교는 최종 우위 근거로 사용하지 않는다.

필수 선택 중 DAY29 최후 선언은 첫 선택지 규칙의 예외로 성 수호(`castle_oath`)를 사용한다. 기본 수비 지침과 함께 성을 지키는 선택을 고정하며, 이 선언 경로는 HP·자원을 보충하지 않는다.

`campaign_v5`는 재도전 허용 진단군으로, 7,200초 제한에 의해 열 번째 회차 DAY26 뒤 중단됐다. 전체 완료 또는 최종 곡선 근거로 쓰지 않는다. 그 이전 모든 시드의 첫 패배까지는 관측했으며 첫 경로 완주는 2/10이었다. 해당 분석은 `diagnostic_retry1.json`에 보존한다. 제한을 14,400초로 늘렸고 최종 실행은 재도전 없는 새 10회다.

최종 배치 비교는 DAY29를 제외한 29개 전투 날짜 중 실제 도달한 모든 진입본을 사용한다. F/E/D/C의 전체 날짜를 집계하고 기존 문제일 DAY20·21·26도 개별 판정한다. 각 실제 도달 상태를 네 배치로 복원하며, 미도달 상태를 가상 전투로 채우지 않는다. 도중에 계획했던 일부 대표 날짜의 비교는 예비 확인용으로만 사용한다.

화면 효과만 생략하는 처리와 일반 처리의 실제 지도 DAY30 비교는 28필드·26유닛·2,234단계가 완전 일치했다(`simulation_parity.json`). 정적 셀 의미 정보는 함정 종류별 읽기 전용 사본으로 보관하므로 함정 상태 변화는 별도 사본에 반영한다. 투사체·피해·난수·이동·성장 계산은 보존한다. B02/B03 기존 직접 검사는 실제 377개 PASS(현재 웨이브 수에 따라 반복 검사 수가 변함), 스토리 정적 검증 73,027개 및 검증기 회귀 13개 PASS다.
