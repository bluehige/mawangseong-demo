# 마왕성 화면 계약

## S00_TITLE — 타이틀

- 플레이어 질문: 새 테스트를 시작할 것인가, 유효한 저장을 이어갈 것인가?
- 핵심 결정: 시작 경로 선택
- 주 행동: 저장 없음 `새 테스트 시작`; 유효 저장 있음 `이어하기 · DAY N`
- P0: 게임명, 현재 테스트 범위, 유효한 시작 행동
- P1: 저장 상태와 이어하기 DAY
- P2: 버전·검수 정보
- 금지: 가짜 난이도 선택, 무효 이어하기, 같은 강도의 다수 메뉴

## S01_INTRUSION_BRIEF — 침입 확인

- 플레이어 질문: 누가 어떤 경로로 오며 이번 DAY에서 무엇을 막아야 하는가?
- 핵심 결정: 어떤 대응을 준비할지 이해
- 주 행동: 배치 시작
- P0: 적 대표·이름, 목표, 고정 침입 순서, DAY 주의 행동
- P1: 특정 적 역할의 경고
- P2: 세부 도감·능력치
- 금지: 실제 encounter와 다른 설명, 배치 전에 불필요한 관리 기능

## S02_PLACEMENT — 배치

- 플레이어 질문: 어디에 어떤 시설과 몬스터를 놓아야 이번 침입을 막을 수 있는가?
- 핵심 결정: 시설·몬스터·구역 조합
- 주 행동: 방어 시작
- P0: 고정 경로 지도, 시설·몬스터 카드, 슬롯, 비용/상태, 시작 가능 여부
- P1: 선택 상세, 유효·비유효 drop, 교체 영향, 시작 차단 이유, Undo 결과
- P2: 세부 능력치와 역할 설명
- P3: 과거 전투 로그
- 의도된 도전: 제한된 자원과 슬롯에서 역할 조합
- 금지: 지도 이동, 상시 방 목록·로그·대형 상세, 판정 없는 장식 슬롯

## S03_DEFENSE_START — countdown

- 플레이어 질문: 현재 배치로 방어를 시작할 것인가?
- 핵심 결정: 배치 snapshot 확정 또는 countdown 취소
- P0: 남은 시간, 시작 상태, 취소 행동
- P1: 확정된 배치 요약
- 금지: 추가 확인창, countdown 후에도 배치 변경 허용, 취소 결과 불명확

## S04_COMBAT — 전투

- 플레이어 질문: 어느 방어선이 위험하며 지금 어떤 명령을 어디에 써야 하는가?
- 핵심 결정: 위협 관찰과 제한된 전술 명령 사용
- P0: 목표·왕좌 HP, 현재 방어선, 전장, 명령력, 4개 명령, 속도
- P1: 실제 telegraph, 남은 시간, 권장 명령, 유효 대상, 명령 성공·실패
- P2: 선택 대상 상세
- P3: 전체 이벤트 로그
- 의도된 도전: 제한된 명령을 적절한 시점·대상에 사용
- 금지: 전장을 덮는 패널, 상시 대형 적 상세, 실제 대상과 다른 강조

## S05_RESULT — 결과

- 플레이어 질문: 왜 이겼거나 졌고 다음 시도에서 무엇을 바꿔야 하는가?
- 핵심 결정: 진행, 배치 수정, 같은 배치 재도전
- P0: 승패, 핵심 원인, 잘한 점, 다음 변경점, 3개 핵심 지표
- P1: 패배 `배치 수정` 주 행동, 동일 배치 재도전 보조 행동
- P2/P3: 접힌 상세 전투 기록
- 금지: 근거 없는 조언, 상세 로그 선노출, 패배 후 같은 행동만 강조

## 공통 상태

모든 조작 요소에 적용 가능한 상태를 확인한다.

- default
- hover
- keyboard/gamepad focus
- selected
- pressed/dragging
- valid target
- invalid target
- disabled with reason
- success
- error with recovery

상태가 필요하지 않은 요소에는 억지로 넣지 않되, 지원 입력에서 현재 상태를 잃지 않는다.
