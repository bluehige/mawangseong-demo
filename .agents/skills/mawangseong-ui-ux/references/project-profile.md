# 마왕성 UI·UX 프로젝트 프로필

## 코어 의존성

- Game UI/UX Rules: `v1.0.0`
- 저장소: `https://github.com/bluehige/study`
- 상속: 범용 코어 → 전략·타워디펜스·관리 패턴 → 마왕성 프로젝트 계약

## 프로젝트

- 엔진: Godot 4.5 계열
- 표현: 2D 쿼터뷰 마왕성 방어
- 핵심 조작: 시설·몬스터 배치, 전술 명령, 자동 전투 관찰과 재배치
- 현재 검증 범위: 제품 2.0 DAY 1~5
- 현재 제품 계보와 정확한 기준 SHA: `docs/handoff/CURRENT.md`에서 매 작업 시작 시 확인

## 활성 팩

- 장르: tactical-strategy, tower-defense, management
- 플랫폼: PC mouse/keyboard, Web PC
- 보조 범위: mobile touch는 명시된 작업에서만
- 패턴: title-entry, intrusion-brief, placement-board, combat-hud, result-screen, onboarding

## 핵심 루프

```text
침입 정보 이해
→ 시설과 몬스터 배치
→ 방어 시작
→ 위협과 방어선 관찰·전술 명령
→ 결과 원인 이해
→ 다음 배치 수정 또는 진행
```

## 감정 목표

- 복잡한 메뉴를 다루는 느낌보다 성을 방어하는 지휘관의 느낌
- 배치한 시설과 몬스터가 실제 전투를 바꾼다는 납득
- 패배해도 다음 시도에서 무엇을 바꿀지 떠오르는 학습감
- 마왕·부하·용사 세계관의 코믹한 매력과 어두운 판타지 분위기

## 의도된 도전

- 제한된 슬롯과 자원에서 역할 조합 선택
- 침입 순서와 적 역할을 보고 방어선 구성
- 전투 중 제한된 명령을 적절한 구역·대상에 사용
- 결과 증거로 다음 배치를 개선

## 금지 마찰

- 첫 행동과 다음 단계가 불명확함
- 쓸모를 알 수 없는 버튼과 중복 패널
- 지도와 전장을 UI가 가림
- 카드·슬롯·명령의 실제 판정과 표시가 다름
- 실패 이유가 없거나 결과가 다음 행동으로 이어지지 않음
- 설명을 읽기 위해 핵심 플레이를 중단해야 함

## 권한 우선순위

```text
AGENTS.md
> 최신 사용자 결정과 docs/handoff/CURRENT.md
> 이 프로젝트 스킬
> 활성 장르·플랫폼 팩
> 범용 코어
```

접근성, 진행 가능성, 실제 정보 정확성은 프로젝트 스타일로 약화하지 않는다.
